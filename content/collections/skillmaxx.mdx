Free directory that install-tests 430 Claude Code plugins, skills, and MCP servers nightly in fresh sandboxes (plus Codex, Grok Build, Cursor, and Pi) and publishes pass/fail matrices, copy-paste install commands, and failure logs.

## Features

- Nightly fresh-sandbox install testing across plugins, skills, and MCP servers
- Pass/fail matrices and failure logs
- Copy-paste install commands

## Use Cases

- Discover working Claude Code plugins, skills, and MCP servers
- Check nightly install health before adding a resource locally
- Track install commands for multiple agent platforms

## TL;DR

SkillMaxx is a public directory and nightly test harness. Visit https://skillmaxx.gilventures.ai/ for results and install commands.
