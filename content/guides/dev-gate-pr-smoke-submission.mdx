## TL;DR

This pilot-only guide verifies that HeyClaude can accept a single raw content entry through the PR-first submission path. The expected workflow is public validation first, then private gate review, then maintainer-owned import handling without auto-merge.

## Validation Scope

The submission intentionally changes one source content file under `content/guides/`. It does not edit generated registry artifacts, README output, workflows, scripts, package metadata, or public data exports.

## Expected Gate Behavior

The submission gate should mark the PR as under review, wait for the required validation lane to pass, run the private Cloudflare-hosted reviewer, and route the result through the configured pilot behavior. Any import remains maintainer-owned and still requires normal checks and manual merge.

## Source Reference

The guide uses the public Claude Code documentation as a canonical source reference for the smoke submission metadata. This third revision exists only to trigger a fresh pilot webhook after the dev gate GitHub client was fixed.
