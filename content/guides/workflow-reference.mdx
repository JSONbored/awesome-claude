## Overview

This reference outlines a simple workflow for planning Claude-assisted implementation work, validating the result, and preserving the reasoning that matters for future maintainers.

## Review loop

Start with a narrow change, run the smallest relevant validation first, and only broaden the test suite when the change touches shared behavior.
