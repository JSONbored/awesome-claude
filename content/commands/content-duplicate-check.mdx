## Scope

Community custom command for **pre-PR duplicate search**. It is not a built-in Claude Code
feature. It operationalizes CONTRIBUTING duplicate guidance and **`pnpm validate:content:strict`**.

## Usage

```
/content-duplicate-check <proposed-slug>
```

## What it does

1. Search **`content/`** for the slug, title fragments, and **`documentationUrl`** domain.
2. Run **`pnpm validate:content:strict`** on the draft file path.
3. Search open and closed PRs with **`gh pr list --search "<slug> OR <source-domain>" --state all`**.
4. Compare against **`examples/content/SUBMISSION_EXAMPLES.md`** rejected duplicate patterns.
5. Document findings in the PR **Duplicate Check** section before submit.

## Source Verification Notes

Verified on **2026-06-16**:

- CONTRIBUTING.md requires duplicate checks across title, slug, repo URL, docs URL, and domains.
- SUBMISSION_EXAMPLES.md documents rejected duplicate and strict-overlap cases.
- **`scripts/validate-content.mjs`** is the local validation entrypoint referenced in CONTRIBUTING.

## Duplicate Check

Distinct from **`content-only-submission-pr-gate-rules`** (rules policy for assistants).
This command is an **operator runbook** with search commands, not a replacement rules file.
