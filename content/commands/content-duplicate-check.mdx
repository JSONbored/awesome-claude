The `/content-duplicate-check` command applies HeyClaude contributor guidance from
[CONTRIBUTING.md](https://github.com/JSONbored/awesome-claude/blob/main/CONTRIBUTING.md)
before you open a one-file content PR.

## Usage

```
/content-duplicate-check <category> <proposed-slug>
```

Provide the target category (`commands`, `hooks`, `skills`, etc.) and the slug you
plan to add under `content/<category>/<slug>.mdx`.

## What it does

When you invoke this command, follow these steps:

1. **Validate inputs.** Confirm `category` matches an existing `content/<category>/` directory and `proposed-slug` uses lowercase kebab-case without shell metacharacters.
2. **Check slug collision.** Search `content/<category>/<proposed-slug>.mdx` and nearby categories for the same slug filename.
3. **Search titles and keywords.** Grep `content/<category>/` for the proposed entry title, provider name, and primary keywords from your draft frontmatter.
4. **Compare canonical URLs.** Search the repository for matching `repoUrl`, `documentationUrl`, `websiteUrl`, and `sourceUrls` values you plan to submit.
5. **Scan open PRs.** When `gh` is available, run `gh pr list --state open --search "content/<category>/" --json number,title,headRefName` and note overlapping slugs or titles.
6. **Run local validation.** When a draft file exists, run `node scripts/validate-content.mjs content/<category>/<proposed-slug>.mdx` and capture schema errors separately from duplicate findings.
7. **Report results.** List exact duplicate paths, overlapping URLs, or open PR numbers. If none are found, state what was searched and recommend proceeding or choosing a different candidate.

## Output format

- **Slug check:** pass/fail with matching paths
- **Title/keyword overlaps:** file paths and matched strings
- **URL overlaps:** field name, URL, and existing entry slug
- **Open PR overlaps:** PR number, title, branch
- **Recommendation:** proceed, revise slug, or pick a different entry

## Requirements

- Repository checkout with `content/` directory present.
- Optional authenticated `gh` CLI for open PR search.

## Duplicate Check

No existing `/content-duplicate-check` command on main. Complements maintainer
validation commands such as `/raycast-feed-validation` by focusing on HeyClaude
content submission deduplication rather than Raycast feed schema checks.
