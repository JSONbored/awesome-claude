## Overview

AdMakeAI makes ad creative for small businesses that advertise on Facebook, Instagram and
TikTok. Its hosted MCP endpoint at `https://admakeai.com/api/mcp` (streamable HTTP) exposes
60 tools, for example:

- **adResearch__listProjects** and **project__createFirst**: the brands (projects) every design belongs to, and setting up a new account's first brand from its website.
- **adGeneration__create** and **adGeneration__generateImage**: a finished ad image built from the brand brief, or an image from a verbatim prompt; poll **adGeneration__getById** until it completes.
- **adSet__generateBatch**: many variations from one brief, for creative testing.
- **adCopyGeneration__generate**: headlines, primary text and CTAs for an ad.
- **videoGeneration__start**: a UGC-style video ad.
- **adResearch__searchCompanies** and **adResearch__getCompanyAds**: the ads any brand is running now, from the Meta Ad Library.
- **zernioAnalytics__accountOverview**: spend and results for a connected Meta ad account, with the previous period for comparison.
- **facebookCampaignDraft__pushDraftCampaign**: Meta draft campaigns, ad sets and ads (a live action that asks first).

## Installation

```bash
claude mcp add --transport http admakeai https://admakeai.com/api/mcp
```

Then run `/mcp`, pick admakeai and sign in through the browser. New accounts get 30 free
credits with no card. In Claude (web or desktop), add a custom connector with the same URL
and click Connect.

## Source Verification Notes

- **https://admakeai.com/agents** documents the MCP endpoint, OAuth sign-in and the REST API.
- **https://admakeai.com/.well-known/oauth-protected-resource/api/mcp** publishes the OAuth metadata (authorization server https://admakeai.com, scopes `mcp:read`, `mcp:write`, `mcp:publish`).
- An unauthenticated `initialize` to the endpoint answers 401 with a `WWW-Authenticate` challenge that points at that metadata.
- **https://github.com/mesmerlord/admakeai-mcp** has the setup, scopes and full tool list, and the server is in the official MCP Registry as `com.admakeai/admakeai`.
