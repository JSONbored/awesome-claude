## Overview

**JustFill** ([justfill.app](https://justfill.app)) provides an official MCP
server for completing **existing** PDF forms without recreating or reflowing
their layout. Instead of converting a PDF to HTML or Word, it resolves form
fields in priority order:

1. **Saved template (confidence 1.0)** — exact geometry from a previously reviewed layout.
2. **Native AcroForm (confidence 1.0)** — embedded PDF form fields read and filled natively.
3. **Vision ML detection (calibrated 0.0–0.95)** — detects text lines, checkboxes, and character comb boxes on flat PDFs and scans (`jpg`/`png`/`tiff`).

The workflow is designed for visual verification: agents inspect labeled field
boxes (`render_preview`), refine detections (`add_field`, `update_field`,
`prune_fields`), preview populated values (`render_filled_preview`), fill the
original document (`fill_pdf`), and lock the layout (`save_template`) so
subsequent fills are deterministic.

Published in the Official MCP Registry as
**`io.github.mrmaciej1/justfill-pdf-forms`** with both a hosted Streamable HTTP
endpoint and an MIT-licensed Python package (`justfill-mcp` on PyPI).

## Key Tools

- `open_pdf(path, min_confidence=0.0, max_pages=10, force_detect=False)` — opens an AcroForm, flat PDF, or scanned image using template -> AcroForm -> ML resolution.
- `render_preview(page_index)` — renders a page image with color-coded labeled field boxes.
- `render_filled_preview(values, page_index)` — previews values drawn in place without consuming a fill.
- `list_fields(page_index?)` — lists detected or native fields with geometry and confidence scores.
- `add_field` / `update_field` / `remove_field` / `prune_fields` — adjust or batch-clean detected fields before filling.
- `fill_pdf(values, output_path, flatten=True)` — fills the original PDF layout and returns overflow warnings.
- `save_template(name)` / `list_templates()` — store and reuse reviewed layouts deterministically.

## Installation

### Hosted Streamable HTTP (OAuth 2.1 — no local install)

Add the remote server in Claude Code:

```bash
claude mcp add --transport http justfill https://justfill.app/api/mcp
```

In Claude Desktop or claude.ai, add `https://justfill.app/api/mcp` as a custom
remote MCP connector and approve the OAuth 2.1 prompt.

JSON config for Streamable HTTP MCP clients:

```json
{
  "mcpServers": {
    "justfill": {
      "url": "https://justfill.app/api/mcp",
      "type": "http"
    }
  }
}
```

### Local MIT stdio client (`uvx`)

For clients that run local stdio MCP servers, use the published PyPI package:

```json
{
  "mcpServers": {
    "justfill": {
      "command": "uvx",
      "args": ["justfill-mcp"]
    }
  }
}
```

Authenticate once with `justfill-mcp login` or pass `JUSTFILL_API_KEY` in the
server `env` block.
