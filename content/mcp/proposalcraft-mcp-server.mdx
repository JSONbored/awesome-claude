## Content

ProposalCraft is a local stdio MCP server that turns a client brief into a
ready-to-send proposal in roughly 30 seconds. It uses your saved winning
proposals as voice and structure reference — not generic templates — so each
draft sounds like you.

It covers the full freelance proposal workflow with 11 tools:

- **analyze_brief** — surfaces budget signals, red flags, scope risks, and questions to ask before you quote.
- **draft_proposal** — generates a proposal from the brief using your library as style reference. Counts against the free-tier limit.
- **improve_proposal** — reviews a draft and returns specific rewrites for weak sections (pricing clarity, opening hook, why-me, scope definition). Free.
- **scope_of_work** — converts an accepted proposal into a formal SOW with deliverables table, milestone timeline, payment schedule, revision policy, change-order clause, and signature block. Free.
- **client_followup** — writes a short, non-pushy follow-up for proposals awaiting a response. Adapts tone to elapsed time. Free.
- **save_proposal / list_proposals / get_proposal / delete_proposal** — local library management.
- **load_examples** — bootstraps 12 bundled industry templates so the library is never empty on first install.
- **usage_status** — reports remaining free drafts.

## Installation

Add to Claude Desktop config:

```json
{
  "mcpServers": {
    "proposalcraft": {
      "command": "npx",
      "args": ["-y", "github:jabbawocky/proposalcraft"]
    }
  }
}
```

Restart Claude Desktop. On first use, run `load_examples` to bootstrap the template library, then ask Claude to draft a proposal from a brief.

## Use Cases

- Draft a project proposal from a client email brief in one step.
- Analyze a brief for scope risks, budget signals, and missing information before quoting.
- Review a proposal draft and get specific rewrites before sending.
- Generate a formal Scope of Work from an accepted proposal.
- Write a follow-up for a proposal that has not received a response.
- Build a library of winning proposals to improve future draft quality.

## Safety and Privacy

ProposalCraft is local-only. It makes no network calls and does not connect to any external service. All data is stored in `~/.proposalcraft/` on the user's machine. Brief and proposal text passes through Claude's standard MCP tool-call channel and is subject to normal Claude Desktop privacy settings.
