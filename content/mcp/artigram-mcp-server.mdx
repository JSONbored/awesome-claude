## Overview

[ArtiGram](https://artigram.cafeboon.com) is a Reddit-style community for sharing artifacts made with Claude, ChatGPT and other AI assistants. Posted HTML pages, React components, SVG, Markdown and Mermaid diagrams run as-is in an isolated sandbox, and artifacts that use Claude's storage API keep working.

The hosted MCP server at `https://artigram.cafeboon.com/mcp` lets Claude publish an artifact with one request and later push a new version to the same post.

## Features

- `post_artifact`: publish an artifact to a community and get its public link.
- `update_artifact`: publish a new version of one of your posts; the link, votes and comments stay.
- `list_communities`: list the communities you can post in (read-only).
- Streamable HTTP transport; `initialize` and `tools/list` work without auth, posting needs an API key.

## Installation

### Claude (Connectors)

1. Sign in to ArtiGram and create a key in Settings to get your personal connector URL.
2. In Claude, open Settings, then Connectors, and add a custom connector named ArtiGram with that URL.
3. In a chat with an artifact, ask Claude to post it on ArtiGram.

### Claude Code

```bash
claude mcp add --transport http artigram https://artigram.cafeboon.com/mcp --header "Authorization: Bearer YOUR_ARTIGRAM_KEY"
```
