## Overview

ByteRay AI provides a hosted Model Context Protocol server registered as `ai.byteray/byteray-mcp` for AI-augmented binary vulnerability analysis. Security researchers can load binaries, navigate functions, inspect assembly or pseudocode, trace data flow, and map attack surfaces through natural language instead of manual RE tooling alone.

The official registry entry lists streamable HTTP at `https://mcp.byteray.ai/mcp` with OAuth and SSO support. Access may require contacting `hi@byteray.ai` for an invite depending on your account tier.

## Features

- Load and navigate binaries with MCP tools for open, goto, and inspect operations.
- Examine assembly, pseudocode, and control-flow graphs for targeted functions.
- Trace taint and SSA-style data flow to follow untrusted input through code paths.
- Review attack surface, sanitization, and vulnerability-oriented analysis helpers.
- Utility tooling for hashes, strings, and supporting RE workflows.

## Use Cases

- Triage a suspicious firmware image before deeper manual reversing.
- Trace user-controlled input through a native library during a product security review.
- Compare two builds of a binary to spot newly introduced risky code paths.
- Generate structured notes for a bug bounty or internal red-team engagement.

## Installation

### Claude (Connectors)

1. Add a custom connector under **Settings → Connectors**.
2. Enter `https://mcp.byteray.ai/mcp`.
3. Complete OAuth when prompted on first tool use.

### Claude Code

```bash
claude mcp add --transport http byteray https://mcp.byteray.ai/mcp
```

## Security

- Analyze only binaries you are authorized to test.
- Keep exploit details inside your organization's disclosure workflow.
- Prefer isolated analysis VMs when working with untrusted samples.

## Troubleshooting

### 401 unauthorized

Complete OAuth sign-in or request access from ByteRay at hi@byteray.ai.

### Connector unavailable

Confirm your MCP client supports remote streamable HTTP transport and OAuth redirects.

### Empty analysis results

Verify the binary format is supported and the upload finished before invoking navigation tools.
