## Overview

AdWeave provides a hosted Model Context Protocol server purpose-built for Meta Ads management. The connector exposes 47 tools covering campaigns, creatives, audiences, and insights so Claude and other MCP clients can operate ad accounts without hand-rolling Graph API calls.

The server is listed in the MCP registry as `ai.adweave/meta-ads-mcp` and hosted at `https://mcp.adweave.ai/meta-ads-mcp`.

## Features

- 47 Meta Ads tools across campaigns, ad sets, ads, creatives, and insights.
- Streamable HTTP transport for modern MCP clients.
- Bearer token authentication with AdWeave API keys.
- Audience and creative management workflows.
- Performance and delivery insight queries.

## Use Cases

- Audit active campaigns and pause underperforming ad sets from chat.
- Create lookalike or retargeting audiences for a product launch.
- Review creative fatigue across image and video assets.
- Pull delivery and spend insights before a weekly performance review.
- Draft campaign structure changes for human approval.

## Installation

### Claude (Connectors)

1. Generate an AdWeave API key with the `aw_` prefix from your dashboard.
2. Add a custom connector pointing to `https://mcp.adweave.ai/meta-ads-mcp`.
3. Set the `Authorization: Bearer aw_...` header on the connector.
4. Connect and invoke Meta Ads tools from a new conversation.

### Claude Code

```bash
claude mcp add --transport http adweave https://mcp.adweave.ai/meta-ads-mcp
claude mcp list
```

### Other MCP clients

Add the connector using the JSON configuration below in your MCP client settings.

## Configuration

```json
{
  "mcpServers": {
    "adweave": {
      "url": "https://mcp.adweave.ai/meta-ads-mcp",
      "type": "http"
    }
  }
}
```

For authenticated setups:

```json
{
  "mcpServers": {
    "adweave": {
      "url": "https://mcp.adweave.ai/meta-ads-mcp",
      "type": "http",
      "headers": {
        "Authorization": "Bearer aw_YOUR_KEY"
      }
    }
  }
}
```

The endpoint requires authentication; unauthenticated requests return an authorization error.

## Security

- Treat write-capable Meta Ads tools like production admin access.
- Rotate AdWeave keys after team member offboarding.
- Scope Meta Business roles to the minimum ad accounts required.

## Troubleshooting

### Authorization required

Add a valid `Authorization: Bearer aw_...` header to the connector.

### 403 on specific tools

Verify the API key and Meta Business role include the target ad account.

### Empty insights

Confirm the date range, attribution window, and that the ad set has delivery in the period.

### Connector not listed

Restart the MCP client after saving connector JSON changes.
