## Overview

RestoSignals is a hosted MCP server (streamable HTTP at `https://api.restosignals.com/mcp`) that finds US restaurants and bars before they open. It fuses public liquor-license applications, food-service permits and new-business filings into one deduped venue with an `opening_score` (0-100). More independent signals give a higher score.

It is listed in the official MCP Registry as `com.restosignals/restosignals`. Client config, an agent skill and plugin manifests are in [github.com/paperandbeyond23-gif/restosignals-mcp](https://github.com/paperandbeyond23-gif/restosignals-mcp); the server itself is hosted.

## Features

- `coverage` (free): live states with venue and hot-lead counts.
- `new_openings`: scored upcoming venues for a state, filtered by `min_score` and `limit`.
- `venue_signals`: the raw liquor, permit and filing rows fused into one venue.
- `watch_area`: a webhook that fires when a new matching venue appears.
- Coverage: New York, Texas, Illinois and California deepest; Oregon, Colorado and Washington lighter.

## Use Cases

- List restaurants about to open in a state, strongest leads first.
- Prospect new venues for POS, beverage distribution, insurance or equipment sales before they open.
- Get alerted when a new bar files for a liquor license in a city.
- Explain a lead's score by showing the underlying public filings.

## Installation

### Claude Code

```bash
claude mcp add --transport http restosignals https://api.restosignals.com/mcp --header "x-api-key: YOUR_RESTOSIGNALS_KEY"
claude mcp list
```

### Other MCP clients

Add a remote HTTP server pointing at `https://api.restosignals.com/mcp` and send your key in the `x-api-key` header.

## Configuration

```json
{
  "mcpServers": {
    "restosignals": {
      "type": "http",
      "url": "https://api.restosignals.com/mcp",
      "headers": { "x-api-key": "YOUR_RESTOSIGNALS_KEY" }
    }
  }
}
```

## Troubleshooting

### Tool calls fail with an auth error

`initialize` and `tools/list` work without a key, but every `tools/call` needs the `x-api-key` header. Add it to the client config and reconnect.

### A state returns no leads

Call `coverage` first. Only the states it returns have data.

### Contact fields are locked

Free keys see whether an owner contact exists on a lead, not the contact itself.
