## Content

Stripe MCP Server is the official Model Context Protocol surface for Stripe. It
lets Claude Code and other MCP-capable clients search Stripe documentation,
inspect Stripe resources, and call Stripe API tools through a hosted remote MCP
server at `https://mcp.stripe.com`.

The strongest default path is OAuth. Stripe documents OAuth sessions for MCP
clients and lets users revoke authorized sessions from Dashboard user settings.
When OAuth is unavailable, Stripe supports restricted API keys in the
`Authorization` bearer header and strongly recommends limiting that key to the
exact functionality the agent needs.

## Features

- Official hosted remote MCP server at `https://mcp.stripe.com`.
- Claude Code setup through `claude mcp add --transport http stripe https://mcp.stripe.com/`.
- OAuth authorization flow for MCP clients that support it.
- Restricted API-key fallback for clients or autonomous agent frameworks that
  cannot use OAuth.
- Local MCP server option through `npx -y @stripe/mcp@latest`.
- Stripe documentation and knowledge-base search tools.
- Stripe resource search and fetch tools.
- API tools for account, balance, customers, coupons, disputes, invoices,
  invoice items, payment links, payment intents, prices, products, refunds, and
  subscriptions.
- Dashboard controls for MCP access and OAuth session revocation.

## Use Cases

- Ask Claude to look up current Stripe documentation while building a Checkout,
  Billing, Connect, or API integration.
- Search Stripe resources during support triage without pasting dashboard data
  manually into a prompt.
- Create sandbox payment links, products, prices, invoices, or customers during
  supervised integration testing.
- Review disputes, subscriptions, invoices, and payment intents with explicit
  human approval before any write action.
- Connect an autonomous agent to Stripe through a restricted API key that grants
  only the minimum required tool surface.

## Installation

### Claude Code hosted server

```sh
claude mcp add --transport http stripe https://mcp.stripe.com/
```

After adding the server, run `/mcp` in Claude Code and complete the Stripe
authorization flow.

### Local server

```sh
npx -y @stripe/mcp@latest --api-key=STRIPE_RESTRICTED_API_KEY
```

Use the local path when you need to run the server process yourself. Keep the
API key restricted and do not commit it into MCP configuration, shell history,
or source code.

## Security Notes

Stripe MCP is powerful because it can bridge an assistant to real payment and
billing operations. Treat every mutating tool as a production action unless it
is clearly scoped to a sandbox account. Require confirmation before creating,
updating, canceling, refunding, invoicing, or otherwise changing Stripe state.
