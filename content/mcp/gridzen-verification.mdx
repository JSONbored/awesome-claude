GridZen Verification is a read-only MCP server for planning identity-verification coverage and exercising sandbox decision results. It is not a live identity-verification service.

Official docs: [https://gridzen.ai/developers/](https://gridzen.ai/developers/).

Remote endpoint: `https://gridzen.ai/developers/mcp` (Streamable HTTP). Official registry name: `ai.gridzen/verification`. Kit: [immurray/gridzen-developer-kit](https://github.com/immurray/gridzen-developer-kit), also on PyPI as `gridzen-developer-kit`.

Tools: `get_coverage`, `plan_verification`, `create_sandbox_verification`, `get_sandbox_verification`, `explain_result`.
