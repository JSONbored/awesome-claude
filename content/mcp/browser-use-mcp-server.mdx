## Content

Browser Use MCP Server is the hosted MCP endpoint for Browser Use Cloud. It lets
Claude and other MCP clients start browser agent sessions in managed cloud
browsers, poll their status and output, send follow-up tasks, and read the
agent's step-by-step messages.

The server is listed in the official MCP registry as
`com.browser-use/browser-use` with the streamable HTTP remote
`https://api.browser-use.com/v3/mcp`. It runs Browser Use API V3 sessions.

## Features

- Hosted streamable HTTP endpoint, no local install for clients with remote MCP
  support.
- Tools: `run_session`, `get_session`, `send_task`, `stop_session`,
  `get_session_messages`, `list_sessions`, and `list_browser_profiles`.
- `run_session` options for model, structured output schema, keep-alive,
  browser profile, workspace, and proxy country.
- Session status includes step count, cost breakdown, and a live view URL.

## Installation

Claude Code:

```bash
claude mcp add -t http -H "Authorization: Bearer YOUR_API_KEY" browser-use https://api.browser-use.com/v3/mcp
```

Cursor (`.cursor/mcp.json`):

```json
{
  "mcpServers": {
    "browser-use": {
      "url": "https://api.browser-use.com/v3/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

Claude Desktop uses the `mcp-remote` bridge; see the Browser Use docs for the
exact `claude_desktop_config.json` block.

## Use Cases

- Ask Claude to complete a multi-step web task in a cloud browser and return
  the result.
- Extract structured data from websites using an output schema.
- Run tasks inside a saved browser profile for sites that need a login.
- Watch a running task through the live view URL and send follow-up
  instructions.

## Safety and Privacy

Browser agents act on real websites and accounts. Keep tasks scoped to approved
sites, review actions before purchases, messages, or account changes, and stop
sessions you no longer need.

Treat task prompts, extracted page content, browser profiles, and the API key as
sensitive. Review which profiles a task can use before automating logged-in
workflows.
