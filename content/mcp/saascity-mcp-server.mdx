## Overview

SaaSCity MCP (`io.saascity/saascity`) is a keyless remote Model Context Protocol server for launching a SaaS or AI product. It audits a homepage before launch, recommends launch directories from a dataset of 1,600+ with Ahrefs DR, link type and price, and can draft a listing on [SaaSCity](https://saascity.io).

The stdio bridge source is MIT-licensed at [nyyhao/saascity-mcp](https://github.com/nyyhao/saascity-mcp). Docs are at [saascity.io/mcp](https://saascity.io/mcp). The server is published in the official MCP Registry.

## Features

- Audit a homepage for launch blockers: HTTPS, noindex, title and meta description, og:image, favicon, canonical, viewport, JSON-LD, robots.txt, sitemap and response time, with a 0-100 score and a fix per problem.
- Find and recommend launch directories filtered by DR, dofollow or nofollow link, price and category.
- Look up one directory's details.
- Search SaaSCity listings, find alternatives and read the leaderboard.
- Draft a SaaSCity listing and check its submission status or badge.

Tools: `check_launch_readiness`, `recommend_launch_directories`, `find_launch_directories`, `get_launch_directory`, `search_listings`, `get_listing`, `find_alternatives`, `get_leaderboard`, `get_launch_weeks`, `get_offers`, `submit_project`, `get_submission_status`, `check_badge`.

## Use Cases

- Check a landing page for SEO and sharing problems before a launch.
- Build a shortlist of free dofollow directories above a DR threshold.
- Plan which launch week to list a product on SaaSCity.

## Installation

### Claude Code

```bash
claude mcp add --transport http saascity https://saascity.io/api/mcp
claude mcp list
```

### Claude (Connectors)

1. Open **Settings → Connectors** and add a custom connector.
2. Enter the URL `https://saascity.io/api/mcp`.
3. No authentication is needed.

## Configuration

```json
{
  "mcpServers": {
    "saascity": {
      "type": "http",
      "url": "https://saascity.io/api/mcp"
    }
  }
}
```

## Security

- All tools except `submit_project` are read-only.
- `submit_project` creates a draft only; a person must sign in and submit it.
- URL-fetching tools only read the public page you name.

## Troubleshooting

### Rate limited

Wait for the retry time in the error message, then call again.

### Audit fails to fetch the page

Make sure the URL is public and does not block non-browser requests.
