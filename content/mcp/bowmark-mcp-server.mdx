## Overview

Bowmark is a hosted Model Context Protocol server that exposes websites as a library of typed functions. Claude looks up what is available with `get_library`, writes a short JavaScript script against those functions, and sends it to `run`. Bowmark executes the script on the live sites and returns structured results, so Claude gets data instead of pages to parse.

The MCP endpoint is `https://api.bowmark.ai/mcp`. stdio bridges and install options live in [bowmark-ai/mcp](https://github.com/bowmark-ai/mcp). Docs are at [bowmark.ai/docs](https://bowmark.ai/docs).

## Features

- One library of functions across many sites, searchable with `get_library`.
- Typed, structured results from `run`.
- Functions are tested on a schedule; ones that stop working are marked degraded or retired.
- Signed-in tasks through saved site connections.
- Hosted streamable HTTP at `api.bowmark.ai/mcp`, plus `uvx bowmark-mcp` and `npx @bowmark/mcp` for stdio hosts.

## Use Cases

- Compare current prices or stock across shops in one request.
- Pull listings, reviews or search results into a table.
- Look up flights, rentals or restaurant availability for a trip.
- Read data from a site you are signed in to, without building a scraper.

## Installation

### Claude (Connectors)

1. Add a custom connector under **Settings > Connectors**.
2. Enter the MCP URL: `https://api.bowmark.ai/mcp`.
3. Sign in or add `Authorization: Bearer YOUR_BOWMARK_API_KEY` when prompted.
4. Enable the connector and ask for something a website shows right now.

### Claude Code

```bash
claude mcp add --transport http bowmark https://api.bowmark.ai/mcp
claude mcp list
```

### stdio hosts

```bash
uvx bowmark-mcp
# or
npx @bowmark/mcp
```

## Configuration

```json
{
  "mcpServers": {
    "bowmark": {
      "url": "https://api.bowmark.ai/mcp",
      "type": "http",
      "headers": {
        "Authorization": "Bearer YOUR_BOWMARK_API_KEY"
      }
    }
  }
}
```

## Security

- Review any script that submits, books or buys before running it unattended.
- Rotate your API key if a shared connector is removed.

## Troubleshooting

### Site not covered

`get_library` returns an index when nothing matches. Try the site's hostname, and use the `report` tool to request coverage.

### 401 with API key

Check the Bearer formatting and that the key is active in your Bowmark dashboard.

### Run failed or returned thin data

Use the `report` tool with the run ID; failing functions are tracked and fixed.
