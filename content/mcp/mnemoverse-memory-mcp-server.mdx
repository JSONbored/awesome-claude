## Content

Mnemoverse Memory is a hosted memory server for AI agents, reached over MCP. What an agent writes in one client
is readable in the next, so a decision made in Claude Code is available in Cursor, VS Code, or ChatGPT under the
same key. Recall is ranked from reported outcomes as well as similarity: tell it that a recalled memory helped or
misled, and what comes back next changes. The MCP server and the Python SDK are MIT licensed; the engine behind
them is a hosted service with Free, Pro, Team, and Enterprise tiers.

## Features

- One API key shared across Claude Code, Cursor, VS Code, and ChatGPT
- Recall re-ranked from reported outcomes, not similarity alone
- Local stdio server from npm (`@mnemoverse/mcp-memory-server`), MIT licensed
- Hosted endpoint at https://mcp.mnemoverse.com/mcp with OAuth sign-in and no key to paste
- Listed in the official MCP Registry as `io.github.mnemoverse/mcp-memory-server`
- Packaged `.mcpb` bundle published with each release (v0.10.1, 2026-09-16)

## Use Cases

- Carry decisions and preferences from one AI tool into the next
- Recall project context at the start of a session instead of restating it
- Mark a recalled memory as helpful or misleading so later recall reflects it

## Installation

### Claude Code

1. Get an API key at https://console.mnemoverse.com
2. Run: claude mcp add mnemoverse -s user -e MNEMOVERSE_API_KEY=mk_live_YOUR_KEY -e MNEMOVERSE_API_URL=https://core.mnemoverse.com/api/v1 -- npx -y @mnemoverse/mcp-memory-server@latest
3. Verify installation: claude mcp list
4. Open a new session and ask about something stored earlier

### Cursor

1. Add the configuration below to `~/.cursor/mcp.json`, merging it with any servers already there
2. Replace `mk_live_YOUR_KEY` with your own key
3. Restart Cursor

## Configuration

```json
{
  "mcpServers": {
    "mnemoverse": {
      "command": "npx",
      "args": ["-y", "@mnemoverse/mcp-memory-server@latest"],
      "env": {
        "MNEMOVERSE_API_KEY": "mk_live_YOUR_KEY",
        "MNEMOVERSE_API_URL": "https://core.mnemoverse.com/api/v1"
      }
    }
  }
}
```

## Security

- The API key is a bearer credential: user-scope config keeps it out of a repository
- Without a key the server starts and lists its tools, and every tool call is refused
- The hosted endpoint uses OAuth sign-in instead of a pasted key
- Stored memories live in the hosted service, so treat the account as the boundary
