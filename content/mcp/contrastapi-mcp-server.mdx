## Overview

Security data over remote MCP: CVE, KEV, CWE and EPSS lookups, a CVE risk score from CVSS, EPSS, KEV and public exploits, CVSS v3 vector parsing, public exploit data, package advisories for nine ecosystems (OSV.dev), DNS, TLS, e-mail (SPF, DMARC, DKIM, MTA-STS), WHOIS/RDAP and IP checks, subdomains from Certificate Transparency, MITRE D3FEND defenses, and watchlists that report changes to CVEs, packages, domains and IPs. Free tier without a key; Pro tier with an API key. Streamable-HTTP transport.

## Usage

claude mcp add --transport http contrastapi https://api.contrastcyber.com/mcp/
claude mcp list

## Auth Requirements

None required for the free tier (hourly credits per IP address). An optional API key (Authorization: Bearer or X-API-Key header) gives more credits and the watchlist tools. See https://api.contrastcyber.com/pricing

## Verification

1. `claude mcp list` shows contrastapi as connected
2. Ask Claude: "Look up CVE-2021-44228 with EPSS and KEV data"
3. The answer includes the CVSS score, the EPSS score and the KEV listing date
