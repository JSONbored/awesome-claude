## Overview

NHTSA Vehicle Recalls & VIN Decoder MCP is a free, keyless hosted Streamable
HTTP Model Context Protocol server backed by official US National Highway
Traffic Safety Administration (NHTSA) public datasets. It lets Claude decode
17-character VINs through vPIC, check open safety recalls (highlighting
Park-It and Park-Outside warnings), inspect consumer safety complaints, and
retrieve 5-Star NCAP crash-test ratings without installing anything locally.

## Installation

Add the hosted Streamable HTTP endpoint directly in Claude Code:

```sh
claude mcp add --transport http nhtsa-recalls https://nhtsa-vehicle-recalls-vin-mcp.lipmichal.workers.dev/mcp
```

Or add the server configuration to your MCP client JSON:

```json
{
  "mcpServers": {
    "nhtsa-recalls": {
      "type": "http",
      "url": "https://nhtsa-vehicle-recalls-vin-mcp.lipmichal.workers.dev/mcp"
    }
  }
}
```

## Use Cases

- Decode a 17-character VIN into make, model, model year, trim, body class, and plant details.
- Check whether a used car or fleet vehicle has open NHTSA safety recalls or urgent Park-Outside notices.
- Summarize NHTSA consumer safety complaints by component for a specific make, model, and year.
- Compare 5-Star NCAP overall, frontal, side, and rollover crash-test ratings before buying a vehicle.

## Safety and Privacy

All tools are read-only and query public US NHTSA datasets over HTTPS. No
credentials, accounts, or local code execution are required. Avoid sending
personal identifying information alongside VIN or vehicle queries, and confirm
recall completion status with NHTSA or an authorized dealer.
