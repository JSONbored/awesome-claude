## Overview

BestPrice MCP is the official Model Context Protocol server for
[BestPrice.gr](https://www.bestprice.gr/), Greece's price-comparison service.
It gives Claude read-only access to shopping decisions, live product search,
current merchant offers and price history for physical products sold in Greece.

The hosted endpoint is `https://mcp.bestprice.gr/mcp` (streamable HTTP, official
registry ID `gr.bestprice/mcp`). The
[TheBestCo/bestprice-mcp](https://github.com/TheBestCo/bestprice-mcp) repository
(Apache-2.0) holds the client install manifests, Claude and Codex plugin
packaging, a bundled shopping Skill, a local stdio bridge for hosts that cannot
speak HTTP, and the browser WebMCP layer. The server itself is hosted by BestPrice.

## Tools

- `get_shopping_decision`: recommendations, comparisons and "should I buy this?" answers with evidence and explicit unknowns.
- `search_products`: finds canonical products by name, model, category or GTIN/EAN barcode and returns product IDs and the catalog minimum item price.
- `compare_offers`: compares current merchant offers for one exact product, separating item price, shipping and delivered total for an optional Greek postcode.
- `get_price_history`: historical pricing for one exact product, to judge whether today's price is low, typical or high.

## Installation

Claude Code:

```sh
claude mcp add --transport http bestprice-shopping https://mcp.bestprice.gr/mcp
```

Or add the remote server to an MCP client configuration:

```json
{
  "mcpServers": {
    "bestprice-shopping": {
      "type": "http",
      "url": "https://mcp.bestprice.gr/mcp"
    }
  }
}
```

The repository can also be added as a Claude plugin marketplace:

```sh
claude plugin marketplace add TheBestCo/bestprice-mcp
claude plugin install bestprice-shopping@bestprice
```

## Use Cases

- Pick a model within a budget and required features, with trade-offs.
- Find where an exact product is cheapest in Greece, including shipping to a postcode.
- Check whether a current price is good using price history.
- Look up a product by barcode.

## Safety and Privacy

The tools are read-only and anonymous. Queries and optional postcodes are sent to
BestPrice.gr. Unknown shipping is reported as unknown, never as free. Results
link to BestPrice product pages, not direct merchant checkout. Queries work in
Greek or English; catalog data and merchant names are returned in Greek.
