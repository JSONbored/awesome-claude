## Overview

**Remembite** is a food log your AI writes to. You tell Claude what you ate. Claude works out the grams, calories, protein, carbs and fat, and Remembite saves the meal with the values Claude sends. It is free and has no ads.

The server is hosted, so there is nothing to run on your own computer. The endpoint is `https://remembite.com/mcp` (streamable HTTP). A request without a token returns `401`, and the response points to the OAuth metadata. This is expected.

## Installation

```bash
claude mcp add --transport http remembite https://remembite.com/mcp
```

Then sign in when the client opens the browser. Setup steps for other clients are at https://remembite.com/connect.
