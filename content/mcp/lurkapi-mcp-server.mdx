## Overview

LurkAPI is a social media data API. Its hosted MCP endpoint at
`https://api.lurkapi.com/mcp` (streamable HTTP) exposes one read-only tool per endpoint,
named `<platform>_<endpoint>`, for example:

- **facebook_search_ads** and **facebook_company_ads**: ads from Meta's Ad Library by keyword or advertiser, with copy, media, landing page and run dates.
- **google_company_ads**, **linkedin_search_ads**, **tiktok_ad_library_search**: Google Ads Transparency Center, LinkedIn Ad Library and TikTok's EU ad library.
- **tiktok_profile**, **instagram_user_posts**, **youtube_channel_videos**, **twitter_user_tweets**: profiles and recent posts.
- **youtube_transcript**, **tiktok_transcript**, **instagram_media_transcript**: what's said in a video.
- **reddit_search** and **reddit_post_comments**: Reddit threads with their comments.
- **account_credit_balance**: the account's balance (free).

`https://api.lurkapi.com/mcp?platforms=facebook,google` lists only those platforms' tools,
and `?compact` gives two tools (`find_endpoints`, `call_endpoint`) for clients that cap tool
counts. Results leave out empty fields and keep one URL per image or video to save tokens.

## Installation

```bash
claude mcp add --transport http lurkapi https://api.lurkapi.com/mcp
```

Then run `/mcp`, pick lurkapi and sign in through the browser. New accounts get 100 free
credits with no card. In Claude (web or desktop), add a custom connector with the same URL
and click Connect.
