## Overview

AI Agents Listing MCP is a remote Model Context Protocol server for the [AI Agents Listing](https://aiagentslisting.com) directory of AI agents, MCP servers and agent skills. It lets an assistant search the directory, browse by category and pricing, read what is trending, find alternatives to a tool and compare listings side by side.

The stdio bridge source is MIT-licensed at [nyyhao/aiagentslisting-mcp](https://github.com/nyyhao/aiagentslisting-mcp). Docs are at [aiagentslisting.com/mcp](https://aiagentslisting.com/mcp). I maintain the server.

## Features

- Search listings by keyword, type, category and pricing model.
- Read one listing in full, including its links and capability details.
- Discover listings by category and see trending and newly launched ones.
- Find alternatives to a given tool and compare several listings side by side.
- Rankings use engagement only. Paid listings are flagged `featured` and are never ranked higher.

Read tools: `search_listings`, `get_listing`, `discover`, `trending`, `new_launches`, `find_alternatives`, `compare`, `list_categories`.

Write tools (OAuth 2.1 sign-in required): `submit_listing`, `submit_review`.

## Use Cases

- Find an MCP server for a specific job and check how it compares with the alternatives.
- See which agents and skills are trending in a category.
- Look for an alternative to a tool you already use.

## Installation

### Claude Code

```bash
claude mcp add --transport http aiagentslisting https://aiagentslisting.com/api/mcp
claude mcp list
```

### Claude (Connectors)

1. Open **Settings → Connectors** and add a custom connector.
2. Enter the URL `https://aiagentslisting.com/api/mcp`.
3. No authentication is needed for the read tools.

### Stdio clients

```bash
npx -y github:nyyhao/aiagentslisting-mcp
```

## Security

- The eight read tools are anonymous and read-only.
- `submit_listing` and `submit_review` need an OAuth 2.1 sign-in with a consent screen.
- Tokens are never forwarded to third parties.

## Troubleshooting

### Rate limited

Wait a moment and call again; anonymous calls are rate limited per IP.

### A write tool returns 401

Sign in again when your client prompts for authorization. The read tools work without it.
