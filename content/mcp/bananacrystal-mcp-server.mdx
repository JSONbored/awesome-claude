## Overview

BananaCrystal gives AI agents a wallet and access to 140+ local currencies.
Agents can get live FX rates and estimate swap fees, swap between
local-currency stablecoins (for example USD to NGN or GHS), send stablecoin
payments to a wallet or BananaCrystal username, add money and cash out to a
bank account after an ID check, and check balances, limits and history.
Payments settle on Hedera.

The server is hosted. There is nothing to install or run locally. The GitHub
repository holds the client configuration files and docs. It is listed in the
official MCP Registry as `com.bananacrystal/mcp`.

## Installation

Claude Code, using OAuth 2.0 sign-in:

```bash
claude mcp add --transport http bananacrystal https://agentic.bananacrystal.com/mcp
```

With an API key instead, send it in the `x-api-key` header:

```json
{
  "mcpServers": {
    "bananacrystal": {
      "type": "http",
      "url": "https://agentic.bananacrystal.com/mcp",
      "headers": {
        "x-api-key": "<your-api-key>"
      }
    }
  }
}
```

OAuth clients can also send `Authorization: Bearer <token>`.

## Guardrails

- Transfers, swaps and withdrawals ask for an email code by default.
- Each key has its own limits.
- Sandbox keys are free and use test balances.
