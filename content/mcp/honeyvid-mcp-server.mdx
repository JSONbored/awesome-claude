## Overview

HoneyVid MCP is HoneyVid's official remote Model Context Protocol server at
`https://honeyvid.ai/mcp` (Streamable HTTP). It signs in with OAuth 2.1 (PKCE,
dynamic client registration), so no API key is pasted into config. It is listed
in the official MCP Registry as `ai.honeyvid/honeyvid`.

HoneyVid puts anyone in a viral AI video: pick a trending video, add one photo
of a person, pet or character and get your own version. The Playground adds
video models such as Kling, Veo and Seedance and several image models.

## Features

- Browse trending video templates and create your own version from one photo.
- Generate videos and images with Playground models; model availability and
  settings come from the live account.
- Quote the credit price before creating; jobs accept a max-credit cap.
- Wait for a job and get the finished MP4 or image back.
- Companion MIT CLI (`npx honeyvid`) and agent skills for the same workflows.

## Installation

### Claude

Customize → Connectors → Add custom connector, name it HoneyVid and paste
`https://honeyvid.ai/mcp`, then click Connect and approve.

### Claude Code

```bash
claude mcp add --transport http honeyvid https://honeyvid.ai/mcp
npx honeyvid skills install --agent claude
```

Then run `/mcp`, choose `honeyvid` and finish the sign-in in your browser.
