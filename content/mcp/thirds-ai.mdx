## Overview

thirds.ai turns one design into many branded PDFs and images. Connect your AI
agent to `https://thirds.ai/mcp` (Streamable HTTP). Clients that support MCP
sign-in need only that URL; other clients send a Bearer API key.

Docs: [thirds.ai/docs/mcp](https://thirds.ai/docs/mcp).
