## Overview

Ownkube is a cloud for personal software. Its hosted MCP server at `https://app.ownkube.io/api/mcp`
connects Claude to an Ownkube account so the agent can deploy a repository, attach managed Postgres
or a Valkey cache, and give each app its own HTTPS hostname. Sign-in is OAuth 2.1 with dynamic
client registration, so there is no API key to paste into a config file. The server is listed in the
official MCP Registry as `io.ownkube/ownkube`.

## Key capabilities

- **Deploys**: web services, background workers and scheduled jobs from a GitHub repository.
- **Data services**: managed Postgres databases and Valkey caches, wired into the app's environment.
- **Configuration**: environment variables, custom domains and alerts.
- **Operations**: build logs, runtime logs, metrics, and rollback to the last healthy revision.
- **Marketplace**: list, check and deploy ready-made apps such as n8n, Metabase and Umami.
- **Billing**: read the wallet balance, current usage and projected monthly cost, and start a top-up.

## Installation

### Claude Code

```bash
claude mcp add --transport http ownkube https://app.ownkube.io/api/mcp
```

The first tool call opens a browser to sign in and approve the organization.

### Cursor

```json
{
  "mcpServers": {
    "ownkube": {
      "url": "https://app.ownkube.io/api/mcp"
    }
  }
}
```

### Claude Desktop

```json
{
  "mcpServers": {
    "ownkube": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://app.ownkube.io/api/mcp"]
    }
  }
}
```

## Requirements

- An Ownkube account with a funded prepaid wallet (top-ups from $5, metered per minute, unused credit never expires).
- A connected GitHub account for repository deploys.
- An MCP client with remote HTTP support, or the `mcp-remote` bridge.

## Security

- Access is scoped to the organization approved on the OAuth consent screen.
- Destructive and billable actions run against real resources; review tool calls before approving them.
- Sensitive operations (live credentials, password resets, point-in-time recovery) are not exposed over MCP.
