## Overview

Anki MCP Server bridges Anki spaced-repetition flashcards to Model Context Protocol clients. Through AnkiConnect it exposes 42 tools for review sessions, note and deck management, media uploads, statistics, and optional Anki GUI automation—turning study into conversational tutoring.

Documentation and examples are at [ankimcp.ai](https://ankimcp.ai). Source and npm package: [ankimcp/anki-mcp-server](https://github.com/ankimcp/anki-mcp-server).

## Features

- Review workflow: sync, due cards, present, and rate.
- Deck, note, tag, model, and media management tools.
- 42 total tools including 11 GUI helpers for note editing.
- MCPB bundle for one-click Claude Desktop installation.
- Optional remote tunnel for cloud clients reaching local Anki.

## Use Cases

- Run a conversational Spanish deck review with explanations.
- Batch-create Arabic vocab cards with RTL model styling.
- Import an image from Downloads into the selected note's front field.
- Inspect collection stats and review history trends.
- Open the card browser and edit a note through GUI tools.

## Installation

### Claude (Connectors)

1. Install Anki and the AnkiConnect add-on; keep Anki running.
2. Add `@ankimcp/anki-mcp-server --stdio` to MCP settings or install the MCPB bundle.
3. Confirm AnkiConnect URL (default http://127.0.0.1:8765).
4. Start a review or note-creation conversation.

### Claude Code

```bash
claude mcp add anki -- npx -y @ankimcp/anki-mcp-server --stdio
claude mcp list
```

### Other MCP clients

Add the connector using the JSON configuration below in your MCP client settings.

## Configuration

```json
{
  "mcpServers": {
    "anki": {
      "command": "npx",
      "args": ["-y", "@ankimcp/anki-mcp-server", "--stdio"]
    }
  }
}
```

For authenticated setups:

```json
{
  "mcpServers": {
    "anki": {
      "command": "npx",
      "args": ["-y", "@ankimcp/anki-mcp-server", "--stdio"],
      "env": {
        "ANKICONNECT_URL": "http://127.0.0.1:8765"
      }
    }
  }
}
```

Set `ANKICONNECT_URL` if AnkiConnect listens on a non-default host or port.

## Security

- Enable read-only mode when exploring unfamiliar decks.
- Confirm destructive tool calls such as deleteNotes or deleteMediaFile.
- Avoid tunneling Anki to the public internet without authentication.

## Troubleshooting

### AnkiConnect refused

Ensure Anki is running and AnkiConnect is installed with the expected port.

### No due cards

Sync with AnkiWeb and verify deck filters in get_due_cards.

### Media upload slow

Prefer file paths or URLs over base64 for storeMediaFile.

### GUI tools noop

Anki desktop must be focused; GUI tools do not replace review-mode shortcuts.
