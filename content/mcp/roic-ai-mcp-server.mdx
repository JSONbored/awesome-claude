## Content

ROIC.ai MCP Server connects Claude and other MCP clients to the ROIC.ai
financial data API. It exposes 25 read-only tools for financial statements,
financial ratios, valuation multiples, earnings call transcripts, historical
stock prices, company profiles, and ticker discovery across public companies on
70+ exchanges.

There are two ways to run it:

- **Hosted:** a Streamable HTTP endpoint at `https://mcp.roic.ai/mcp` with OAuth
  sign-in, so there is no API key to configure in the client.
- **Self-hosted:** the MIT-licensed Node.js server in `roicai/agents-plugin`,
  which authenticates to the ROIC.ai REST API with `ROIC_API_KEY`.

## Features

- Income statements, balance sheets, and cash flow statements, annual or quarterly.
- Profitability ratios (ROE, ROA, ROIC, margins), credit ratios (debt/EBITDA,
  debt/equity, interest coverage), liquidity ratios, and working capital ratios.
- Valuation multiples (P/E, P/B, P/S, EV/EBITDA), enterprise value, and per-share data.
- Earnings call transcripts by year and quarter, plus the latest call.
- End-of-day and historical OHLCV stock prices with date ranges.
- Company profiles and company news.
- Ticker search and resolution by symbol, name, CIK, CUSIP, or ISIN.
- Lists of exchanges, sectors, industries, and countries with ticker counts.

## Installation

### Hosted endpoint (Claude Code)

```bash
claude mcp add --transport http roicai https://mcp.roic.ai/mcp
```

The client opens an OAuth sign-in on first use.

### Hosted endpoint (generic MCP client)

```json
{
  "mcpServers": {
    "roicai": {
      "type": "http",
      "url": "https://mcp.roic.ai/mcp"
    }
  }
}
```

### Self-hosted server

Get an API key from `https://www.roic.ai/dashboard`, then run the open-source
server from a clone of the repository:

```bash
git clone https://github.com/roicai/agents-plugin.git
cd agents-plugin
npm install
ROIC_API_KEY=your_key npm start
```

For MCP clients that launch stdio servers:

```json
{
  "mcpServers": {
    "roicai": {
      "command": "node",
      "args": ["PATH_TO_AGENTS_PLUGIN/server.js"],
      "env": {
        "ROIC_API_KEY": "YOUR_API_KEY"
      }
    }
  }
}
```

`ROIC_API_BASE` overrides the API base URL (default `https://api.roic.ai/v2`).

## Use Cases

- Compare margins and ROE for two companies over the last several years.
- Check a company's P/E, EV/EBITDA, and P/S against its own history.
- Ask what management said about a topic in the latest earnings call.
- Pull daily historical prices for a ticker and date range.
- Resolve a CUSIP or ISIN to a ticker before querying statements.

## Safety and Privacy

All tools are read-only and only call the ROIC.ai API. Prices are end-of-day,
not intraday, and plan limits apply (the free tier allows 5 requests per minute
and 2 years of history). Treat model-generated analysis as draft research and
verify figures before using them in decisions or client material.

Keep `ROIC_API_KEY` out of repositories and shared logs. Ticker queries can
reveal research interests, so avoid sending private holdings or material
non-public information in prompts.
