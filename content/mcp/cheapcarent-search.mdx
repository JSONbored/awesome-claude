## Overview

Official CheapCarRent MCP server for car rental search. It covers 15,000 pickup points in 46 countries and 19 languages. Transport is Streamable HTTP. No account or API key is required. Tools are read-only: `list_locations` and `search_cars`.

Source: https://github.com/aleksandrjefimov4-crypto/cheapcarent-mcp (MIT). Docs: https://cheapcarent.com/developers. Official MCP Registry name: `com.cheapcarent/search`.

## Usage

```bash
claude mcp add cheapcarent-search --transport http https://cheapcarent.com/mcp
```

## Auth Requirements

No authentication. The server is read-only.

## Verification

The hosted endpoint is `https://cheapcarent.com/mcp` (Streamable HTTP, POST). Documentation is at https://cheapcarent.com/developers.
