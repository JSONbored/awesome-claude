## Setup

Install the PyPI package using the install command above. Add the SDK extras for the encrypted store and file extraction.

```sh
pipx inject --force wa-mcp-server 'wa-mcp-sdk[encryption,files]'
```

Build and start the Go bridge, then scan its QR code under **Linked devices** on your phone. Keep the bridge running while messages sync. Replace `CONFIG_FILE` in the Claude Desktop configuration with the absolute path to the bridge's `config.json`, then restart the client. [Bridge setup](https://github.com/tsahospital-beep/wa-mcp/blob/main/docs/getting-started.md)

## Verification

Run `bridge_status` to check that the bridge is logged in and the message store is available. Search for a phrase from a synced message. To search speech from voice notes, configure a transcription backend and transcribe the clips first. [Voice transcription](https://github.com/tsahospital-beep/wa-mcp/blob/main/docs/guides/transcription.md)
