## Overview

RunAPI MCP Server connects Claude and other MCP-compatible clients to RunAPI's
model catalog. Discovery tools can list models and actions, inspect input
constraints, search prompt examples, and check current runtime pricing. After
authentication, the server can create media tasks, poll task status, and check
account balance.

The package supports local stdio MCP clients through npm and a hosted
Streamable HTTP endpoint at `https://mcp.runapi.ai/mcp`. The local package can
also open the RunAPI login flow and save shared credentials for later calls.

## Installation

For a local Claude Code installation:

```sh
claude mcp add runapi -s user -- npx -y @runapi.ai/mcp
```

For other local MCP clients, use the JSON configuration below:

```json
{
  "mcpServers": {
    "runapi": {
      "command": "npx",
      "args": ["-y", "@runapi.ai/mcp"]
    }
  }
}
```

Remote-capable clients can connect to:

```text
https://mcp.runapi.ai/mcp
```

Use OAuth where the client supports it, or provide a RunAPI API key through the
client's secret configuration. For headless local hosts, set `RUNAPI_API_KEY`
before starting the MCP client.

## Use Cases

- Find compatible image, video, audio, music, or language models from the live catalog.
- Inspect required fields, constraints, and current pricing before creating a task.
- Search reusable prompt examples and adapt them to a selected model.
- Submit an asynchronous task and poll it later with its task ID.
- Check account balance and spending metrics from an authenticated client.
