## Overview

The **Taplio for LinkedIn MCP Server** is the official remote Model Context Protocol server from Taplio, the
LinkedIn growth tool. It is hosted by Taplio at `https://mcp.taplio.com/` (Streamable HTTP, OAuth 2.1
with PKCE and dynamic client registration); there is nothing to build or run locally. It is
published in the official MCP Registry as `io.github.TaplioOfficial/taplio-linkedin-mcp`.

## Key capabilities

The server exposes 38 tools, all scoped to the authenticated user's own Taplio and LinkedIn account:

- **Account and analytics**: identity and content preferences (`get_me`), your posts (`list_posts`,
  `get_post`), account analytics (`get_analytics_overview`) and per-post analytics
  (`get_post_analytics`).
- **Drafts and media**: create, edit and delete drafts, and upload or attach images, videos, GIFs
  and PDFs.
- **Schedule and publish**: schedule a draft (`schedule_draft`), move it back to drafts
  (`unschedule`) or publish it now (`publish_draft`).
- **Inspiration**: search other creators' LinkedIn posts (`search_inspiration`).
- **Engage**: find posts worth commenting on (`find_posts_to_comment`) and comments that deserve a
  reply (`find_comments_to_reply`), draft comments and replies, queue them
  (`commit_comment_draft`), and queue likes (`like_post`).
- **Network**: search Taplio's lead database for prospects by role, seniority, department, industry,
  country and company (`search_leads`, Pro plan), queue connection requests (`send_connection_request`)
  and follow their status.

The [tool reference](https://github.com/TaplioOfficial/taplio-linkedin-mcp/blob/main/docs/tools.md)
classifies every tool as read, write or sensitive write, and lists rate limits and plan
requirements.

## Installation

### Claude Code

```bash
claude mcp add --transport http taplio https://mcp.taplio.com/
```

Run `/mcp` in Claude Code and authorize `taplio` in the browser when prompted.

### Claude Desktop and claude.ai

Install the Taplio connector from Customize > Connectors (search "Taplio"), or add a custom
connector with the URL `https://mcp.taplio.com/`, then approve the Taplio sign-in.

### Claude Code plugin (skills)

The [Taplio plugin](https://github.com/TaplioOfficial/taplio-linkedin-plugin) adds LinkedIn
workflow skills that run on this server. It contains skills only, so connect the server first:

```bash
/plugin marketplace add TaplioOfficial/taplio-linkedin-plugin
/plugin install taplio@taplio
```

### Other clients

Any client that supports remote MCP servers over HTTP can use:

```json
{
  "mcpServers": {
    "taplio": {
      "type": "http",
      "url": "https://mcp.taplio.com/"
    }
  }
}
```

The [README](https://github.com/TaplioOfficial/taplio-linkedin-mcp#readme) has per-client setup
for VS Code, Cursor, Windsurf and others.
