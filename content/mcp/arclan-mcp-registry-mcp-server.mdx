## Overview

Arclan maintains a validated agent tool registry that continuously indexes MCP servers, OpenAPI tools, and AI plugins from GitHub, npm, PyPI, Smithery, and well-known endpoints. Each candidate undergoes live handshake validation, latency measurement, and description scanning before receiving reliability scores.

The registry MCP endpoint is `https://arclan.ai/mcp`, listed as `ai.arclan/registry` in the official MCP registry.

## Features

- Discover MCP servers with uptime, latency, and handshake success metrics.
- Filter by auth type, capability, and trust state.
- Live handshake validation with 10-second timeout.
- Description scanning for prompt injection and exfiltration patterns.
- Catalogues stdio, OpenAPI, and remote HTTP MCP entries.

## Use Cases

- Find a read-only finance MCP server with high 7-day uptime.
- Compare auth-gated versus live-open servers for a CRM integration.
- Avoid degraded or zombie registry entries before agent rollout.
- Discover OpenAPI tools alongside MCP servers for hybrid agents.
- Audit which MCP tools match a capability keyword.

## Installation

### Claude (Connectors)

1. Add `https://arclan.ai/mcp` as a custom MCP connector.
2. Query the registry with capability, auth, or reliability filters.
3. Review trust state and endpoint URL before adding discovered servers.
4. Connect to chosen third-party MCP servers separately in your client.

### Claude Code

```bash
claude mcp add --transport http arclan https://arclan.ai/mcp
claude mcp list
```

### Other MCP clients

Add the connector using the JSON configuration below in your MCP client settings.

## Configuration

```json
{
  "mcpServers": {
    "arclan": {
      "url": "https://arclan.ai/mcp",
      "type": "http"
    }
  }
}
```

Arclan is a discovery layer; add target server URLs as separate connectors after validation.

## Security

- Treat registry metadata as advisory; perform your own security review before production use.
- Prefer Auth Gated or verified publishers for sensitive data integrations.
- Do not assume prompt-injection scanning catches all malicious tool descriptions.

## Troubleshooting

### Cannot GET /mcp in browser

Use an MCP client; the endpoint speaks MCP over HTTP POST, not browser GET.

### Empty search results

Broaden capability filters or include auth-gated entries.

### Stale uptime scores

Retry later; Arclan continuously re-validates candidates.

### Third-party connect fails

Configure the discovered server's auth separately; Arclan only indexes it.
