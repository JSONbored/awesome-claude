## Overview

Datacircle's hosted MCP server answers one question: which GTM API is best. It has two
read-only tools: **list_apis** gives every API on the sheet with its plan and provider
counts, and **search_plans** finds plans by API, provider or price.

## Installation

```bash
claude mcp add --transport http datacircle https://api.datacircle.dev/mcp
```

## Source Verification Notes

Verified on **2026-11-07**:

- `tools/list` at **https://api.datacircle.dev/mcp** returns `list_apis` and `search_plans`.
- The same data is open over REST at **https://api.datacircle.dev/v1** (spec: **https://api.datacircle.dev/v1/openapi.json**).
