## Content

Levea MCP Server (`levea-mcp-server`) is an open-source Model Context Protocol
adapter that connects Claude Code, Claude Desktop, and other MCP clients to the
Levea cloud video editing engine. It supports both high-level goal delegation
(`autonomous_edit`) and direct deterministic NLE tool control (`search_tools`,
`get_action_schema`, `execute_action`, `execute_batch`, `render_preview`,
`search_skills`, `load_skill`) across 37 MCP tools and 189+ canonical video
editing actions.

## Features

- 37 annotated MCP tools covering both autonomous goal delegation and direct deterministic timeline editing.
- Mode A goal delegation (`autonomous_edit`, `autonomous_edit_streaming`, `queue_edit`) with optional `requirePlanApproval` before mutating a project.
- Mode B direct canonical control (`search_tools`, `get_action_schema`, `execute_action`, `execute_batch`, `render_preview`) unlocking 189+ NLE actions and 13 read/measurement tools.
- 280+ word-by-word animated caption templates (`list_caption_templates`, `apply_caption_template`), 9:16 active-speaker reframing, silence removal, B-roll, motion graphics, audio cleanup, and auto-ducking.
- Real GPU-composited JPEG frame inspection via `render_preview` so Claude can visually verify titles, captions, and layout before exporting MP4.
- Supports both local stdio (`npx -y levea-mcp-server`) and hosted Streamable HTTP with OAuth 2.1 + PKCE (`https://api.livecore.ai/api/v1/misc/mcp`).
- MIT license.

## Installation

Add the stdio server in Claude Code or Claude Desktop:

```json
{
  "mcpServers": {
    "levea": {
      "command": "npx",
      "args": ["-y", "levea-mcp-server"],
      "env": {
        "LEVEA_API_URL": "https://api.livecore.ai",
        "LEVEA_API_KEY": "<your-levea-api-key>"
      }
    }
  }
}
```

Or connect via Streamable HTTP in Claude Code:

```sh
claude mcp add --transport http levea https://api.livecore.ai/api/v1/misc/mcp
```

## Use Cases

- Turn long-form podcasts, interviews, or demos into vertical 9:16 Shorts, Reels, and TikTok clips with active-speaker reframing and animated captions.
- Inspect project timelines and transcripts with `list_layers` and `query_transcript`, apply surgical cuts or color grades with `execute_batch`, and verify rendered frames with `render_preview`.
- Maintain reusable brand kits (`create_brand_kit`, `list_brand_kits`) and custom caption templates across recurring video series.

## Safety and Privacy

Levea MCP Server delegates video processing and rendering to the configured
`LEVEA_API_URL` cloud service. Mutating calls alter remote project timelines and
can start asynchronous MP4 export jobs that consume account render quota. Use
`requirePlanApproval: true` or read-only inspection tools (`list_layers`,
`render_preview`) before committing destructive edits.

Prompts, media URLs, transcripts, and brand assets passed to tool calls are sent
over HTTPS to the remote API. The local stdio package does not scan local disks
or execute shell commands. Keep `LEVEA_API_KEY` stored in environment variables
and set `LEVEA_TELEMETRY=off` if you wish to disable anonymous usage pings.
