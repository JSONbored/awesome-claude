## Overview

MailVeri MCP Server is MailVeri's official Model Context Protocol server. It lets
Claude and other MCP-capable clients verify email deliverability, check remaining
credits, and manage bulk verification batches. The server is written in Python,
licensed under MIT, and runs locally with `uvx` from the pinned revision
https://github.com/mailveri/mailveri-mcp/tree/01f1bbd0aa1a454b65d6900937dd42d2876a05d9. It is not published on PyPI
or npm.

## Features

The server exposes these tools:

- `mailveri_verify_email` - verify one email (returns statuses such as VALID, INVALID, DISPOSABLE, ROLE_ACCOUNT, CATCH_ALL, and FULL_INBOX)
- `mailveri_get_balance` - remaining verification credits
- `mailveri_verify_batch` - queue a list of emails (minimum 2) for background verification
- `mailveri_get_batch_status` - progress, status, and download links for a batch
- `mailveri_download_batch_result` - download link for completed results (ZIP or filtered CSV)
- `mailveri_delete_batch` - cancel or delete a batch

Default transport is stdio. SSE transport is available for local multi-client setups:

```bash
export MAILVERI_API_KEY="YOUR_MAILVERI_API_KEY"
mailveri-mcp --transport sse --host 127.0.0.1 --port 8000
```

## Installation

Requires [uv](https://docs.astral.sh/uv/) and git. Then add the server with a MailVeri API key from https://app.mailveri.com/api-keys/:

```bash
claude mcp add mailveri -e MAILVERI_API_KEY=YOUR_MAILVERI_API_KEY -- uvx --from git+https://github.com/mailveri/mailveri-mcp.git@01f1bbd0aa1a454b65d6900937dd42d2876a05d9 mailveri-mcp
```

### Claude Desktop, Cursor, Codex, and other stdio clients

```json
{
  "mcpServers": {
    "mailveri": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://github.com/mailveri/mailveri-mcp.git@01f1bbd0aa1a454b65d6900937dd42d2876a05d9",
        "mailveri-mcp"
      ],
      "env": {
        "MAILVERI_API_KEY": "YOUR_MAILVERI_API_KEY"
      }
    }
  }
}
```

Optional environment variable: `MAILVERI_BASE_URL` (default `https://api.mailveri.com`).
