## Overview

SkyAccess is the world's largest empty leg marketplace by listing volume. Its hosted MCP server lets Claude and other MCP clients search 5,000+ live empty leg flights from 900+ FAA Part 135 (and international equivalent) certified charter operators, often 25 to 75% below a comparable full charter. It also returns indicative charter price estimates and a booking link the traveler opens to review and book.

The server is free and anonymous: no account, sign-up, API key or OAuth. Nothing is installed locally. It is published in the official MCP Registry as `com.skyaccess/skyaccess`, and the source repository is MIT licensed.

## Features

- Search empty leg flights by origin, destination, date range, passenger count and an optional maximum price
- Whole-aircraft prices in USD; taxes and fees are shown at checkout
- Indicative charter price ranges per aircraft category, with flight time
- Booking links that create no booking or hold until the traveler completes them
- Tools: `search_empty_legs`, `get_flight`, `booking_handoff`, `get_charter_estimate`, `request_booking`

## Installation

Claude Code:

```bash
claude mcp add --transport http skyaccess https://mcp.skyaccess.com/mcp
```

Claude Code plugin (the same server, plus a skill that tells Claude when to use each tool):

```bash
claude plugin marketplace add sky-access/skyaccess-mcp
claude plugin install skyaccess@skyaccess
```

Claude (claude.ai and Claude Desktop): Settings, Connectors, Add custom connector, then paste `https://mcp.skyaccess.com/mcp` and leave authentication empty.

## Configuration

Project `.mcp.json` for Claude Code:

```json
{
  "mcpServers": {
    "skyaccess": {
      "type": "http",
      "url": "https://mcp.skyaccess.com/mcp"
    }
  }
}
```

Cursor (`~/.cursor/mcp.json`):

```json
{ "mcpServers": { "skyaccess": { "url": "https://mcp.skyaccess.com/mcp" } } }
```

Connection details: Streamable HTTP, stateless (no `Mcp-Session-Id`). Prices and estimates are in USD. Coverage is global, with most inventory in the United States.

## Verification

Ask Claude: "Find me a private jet from Los Angeles to Las Vegas this week for 4 people." Claude should call `search_empty_legs` and return matching flights with route, departure time, aircraft, price and a booking link. Inventory changes all the time, so results differ from run to run.

To check the connection without Claude, list the tools:

```bash
curl -sS https://mcp.skyaccess.com/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
