## Overview

Agentic Shelf turns an e-commerce catalog into a live Model Context Protocol endpoint that AI shopping agents can query in real time. Instead of scraping stale product pages, agents read current SKU metadata, stock levels, and pricing from connected Shopify, Amazon, WooCommerce, BigCommerce, or headless storefronts.

The hosted connector is listed as `ai.agenticshelf/mcp` at `https://api.agenticshelf.ai/mcp`. Source references are in [vboykoCTO/agentic-shelf](https://github.com/vboykoCTO/agentic-shelf).

## Features

- Live product catalog, stock, and pricing over streamable HTTP.
- Support for Shopify, Amazon, WooCommerce, BigCommerce, and headless setups.
- Designed for AI shopping assistants and agent commerce workflows.
- Optional citation audits measuring AI assistant product surfacing.
- Free early access during beta.

## Use Cases

- Answer shopper questions about in-stock variants and current price.
- Compare catalog coverage before and after adding MCP product context.
- Let a support agent look up SKU availability during chat sessions.
- Feed an AI merchandising workflow with live inventory snapshots.
- Validate that AI assistants cite your store with fresh catalog data.

## Installation

### Claude (Connectors)

1. Connect your storefront in the Agentic Shelf dashboard.
2. Add `https://api.agenticshelf.ai/mcp` as a custom MCP connector.
3. Authenticate with your Agentic Shelf token if prompted.
4. Query product or inventory tools from a new assistant conversation.

### Claude Code

```bash
claude mcp add --transport http agentic-shelf https://api.agenticshelf.ai/mcp
claude mcp list
```

### Other MCP clients

Add the connector using the JSON configuration below in your MCP client settings.

## Configuration

```json
{
  "mcpServers": {
    "agentic-shelf": {
      "url": "https://api.agenticshelf.ai/mcp",
      "type": "http"
    }
  }
}
```

For authenticated setups:

```json
{
  "mcpServers": {
    "agentic-shelf": {
      "url": "https://api.agenticshelf.ai/mcp",
      "type": "http",
      "headers": {
        "Authorization": "Bearer YOUR_SHELF_TOKEN"
      }
    }
  }
}
```

Add an Authorization header when your workspace requires an Agentic Shelf API token.

## Security

- Treat live pricing and inventory as business-critical; confirm before automated repricing.
- Use separate beta credentials when testing against production catalogs.
- Review commerce platform API scopes granted to Agentic Shelf.

## Troubleshooting

### Empty catalog

Verify the storefront connection succeeded in the Agentic Shelf dashboard.

### Stale inventory

Commerce APIs may cache; retry or force sync from the platform admin.

### 401 unauthorized

Refresh the Bearer token in connector headers.

### Wrong platform data

Confirm the connector is linked to the intended store ID.
