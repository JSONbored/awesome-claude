## Overview

The **Buddy MCP Server** is the official remote Model Context Protocol server from
[Buddy](https://buddy.works). It lets Claude run and watch CI/CD pipelines, deploy to
environments, create sandboxes, publish packages, manage domains and routing, and read run
logs. Buddy hosts the server, so OAuth and token setups need no local install.

## Endpoints

| Region | Endpoint |
|---|---|
| US | `https://mcp.buddy.works/mcp` |
| Europe | `https://mcp.eu.buddy.works/mcp` |
| Asia | `https://mcp.asia.buddy.works/mcp` |

## Tool categories

Tools are grouped into 12 categories: `user`, `workspaces`, `projects`, `members`,
`pipelines`, `source`, `targets`, `sandboxes`, `packages`, `domains`, `distros`, `suites`.
Pass `?tools=pipelines,source` (or `--tools` with `bdy mcp`) to expose only what the agent
needs.

## Installation

### Claude Code (OAuth)

```bash
claude mcp add --transport http buddy https://mcp.buddy.works/mcp
```

The client opens a browser login and scope approval on first use.

### Personal access token

Send the token as a `Bearer` header, for CI and agents without a browser:

```json
{
  "mcpServers": {
    "buddy": {
      "url": "https://mcp.buddy.works/mcp",
      "headers": { "Authorization": "Bearer <YOUR_TOKEN>" }
    }
  }
}
```

### Buddy CLI proxy

```bash
npm install -g bdy
bdy login
claude mcp add buddy -- bdy mcp --tools pipelines,source
```
