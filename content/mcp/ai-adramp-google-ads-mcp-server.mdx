## Overview

AdRamp publishes a free, public Model Context Protocol server that connects AI assistants to Google Ads reporting data. After a one-time Google OAuth authorisation, Claude and other MCP clients can ask plain-English questions about ROAS, keyword performance, search terms, and daily spend without switching dashboards.

Documentation and setup steps are at [adramp.ai/mcp](https://adramp.ai/mcp). The registry lists the server as `ai.adramp/google-ads` at `https://mcp.adramp.ai`.

## Features

- Read-only Google Ads account, campaign, ad group, and keyword insights.
- Search term analysis for wasteful spend discovery.
- Side-by-side period comparisons and daily spend breakdowns.
- OAuth authentication with no API keys or usage caps on the public server.
- Streamable HTTP transport compatible with Claude, Cursor, and VS Code.

## Use Cases

- Ask for ROAS across all campaigns for the current month.
- Compare last 7 days versus the previous 7 days for top campaigns.
- Find search terms that spend but do not convert.
- Identify campaigns overspending relative to conversion rate.
- Summarise daily spend for the past 30 days before a budget meeting.

## Installation

### Claude (Connectors)

1. Open **Settings → Connectors → Add custom connector** in Claude.
2. Name the connector AdRamp and paste `https://mcp.adramp.ai`.
3. Click **Connect** and complete Google OAuth for read-only Ads access.
4. Start a new chat and ask performance questions in plain English.

### Claude Code

```bash
claude mcp add --transport http adramp https://mcp.adramp.ai
claude mcp list
```

### Other MCP clients

Add the connector using the JSON configuration below in your MCP client settings.

## Configuration

```json
{
  "mcpServers": {
    "adramp": {
      "url": "https://mcp.adramp.ai",
      "type": "http"
    }
  }
}
```

For authenticated setups:

```json
{
  "mcpServers": {
    "adramp": {
      "url": "https://mcp.adramp.ai/sse",
      "type": "http"
    }
  }
}
```

Some clients accept the legacy SSE alias at `https://mcp.adramp.ai/sse`; prefer the root streamable HTTP URL when supported.

## Security

- Read-only OAuth cannot mutate campaigns, but still exposes sensitive performance data.
- Revoke AdRamp OAuth access when removing the connector.
- Use separate Google accounts or MCC views when testing to avoid leaking client data.

## Troubleshooting

### OAuth loop fails

Ensure pop-ups are allowed and you grant read access to the intended Google Ads account.

### No data returned

Verify the account has recent spend and remember reporting latency of several hours.

### Cursor SSE errors

Try the `/sse` URL alias if your client does not yet support streamable HTTP at the root path.

### Stale metrics

Google Ads API reporting may lag; confirm date ranges and account time zone.
