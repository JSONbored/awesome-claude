## Overview

The **lemlist MCP Server** is the official remote Model Context Protocol server from lemlist,
the multichannel sales outreach platform. It is hosted by lemlist at `https://app.lemlist.com/mcp`
(Streamable HTTP); there is nothing to build or run locally. It is published in the official MCP
Registry as `io.github.l3mpire/lemlist`.

## Key capabilities

- **Campaigns**: list campaigns (`get_campaigns`), read their stats (`get_campaigns_stats`), create a
  campaign with an email and LinkedIn sequence (`create_campaign_with_sequence`), and launch it
  (`launch_campaign`).
- **Leads**: add leads to a campaign (`add_leads_to_campaign`) and search the lemlist B2B people
  database (`lemleads_search`).
- **Deliverability**: check the health of a sending domain (`check_domain_health`).

The [lemlist plugin repository](https://github.com/l3mpire/lemlist-plugin) also ships four workflow
skills built on these tools: finding leads, launching a campaign, reporting on campaign stats, and a
deliverability check.

## Installation

### Claude Code (OAuth)

```bash
claude mcp add --transport http lemlist https://app.lemlist.com/mcp
```

Run `/mcp` in Claude Code to sign in. The lemlist consent screen lets you pick the team to connect.

### Claude Code plugin (server and skills)

```bash
/plugin marketplace add l3mpire/lemlist-plugin
/plugin install lemlist@lemlist
```

### Claude Desktop and other clients

Add a remote MCP server with the URL `https://app.lemlist.com/mcp`. To use an API key instead of
OAuth, follow the [setup guide](https://help.lemlist.com/en/articles/13728466-set-up-the-lemlist-mcp-server-in-your-llm-client-oauth-or-api-key).
