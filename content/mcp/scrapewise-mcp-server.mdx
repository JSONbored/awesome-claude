## Content

Scrapewise is a hosted remote MCP server that gives Claude clean, matched product and price data from any website. It exposes tools for Google search, local business lookup, Amazon product and seller data, idealo price offers, Google Trends, page fetching, and product data extraction and cleaning.

These sources were reviewed on **2026-11-14**.

## Features

- `get_product_data` reads product fields (name, price, currency, availability, SKU, EAN) from the product pages of one shop.
- `search_amazon`, `get_amazon_product` and `amazon_seller_leads` cover Amazon search, product pages, offers and seller details.
- `idealo_offers` returns the shop offers idealo lists for a product.
- `google_search`, `google_trends`, `find_local_businesses` and `fetch_page` cover search, demand trends, local businesses and single pages.
- `clean_product_data` adds the price in EUR and price per unit, trims text and removes duplicate rows, for free.

## Installation

```bash
claude mcp add --transport http scrapewise https://mcp.scrapewise.ai/mcp
```

Claude opens the Scrapewise sign-in the first time a tool is used. The repository is also a Claude Code plugin: `/plugin marketplace add BEBOTECH-OU/scrapewise-mcp`, then `/plugin install scrapewise`.

## Configuration

```json
{
  "mcpServers": {
    "scrapewise": {
      "url": "https://mcp.scrapewise.ai/mcp"
    }
  }
}
```

Clients that cannot use OAuth can send an API key as an `Authorization: Bearer` header; create the key in the Scrapewise portal.

## Use Cases

- Check a competitor's price on a list of product pages.
- See who sells a product on idealo and at what price.
- Compare an Amazon marketplace with another one for a keyword.
- Clean mixed-currency product rows into comparable EUR and per-unit prices.

## Safety and Privacy

The server is remote and runs no code on your machine. Requests you make are sent to the Scrapewise service. Paying tools show a price first (`quote_only=true`), and a read-only key cannot spend credit.

## Troubleshooting

### Claude shows an authentication error

Sign in with a Scrapewise account when prompted, or send a valid API key in the `Authorization: Bearer` header.

### A tool says the wallet has no balance

The free trial is 5 requests. Top up the prepaid balance in the Scrapewise portal.
