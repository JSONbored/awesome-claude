## Overview

DeepLedger turns MCP-compatible assistants into AI accounting operators for QuickBooks Online. Through a single hosted endpoint, agents can record bills and expenses, reconcile accounts, assist with month-end close, clean up books, and prepare audit-ready workflows while humans review the results.

The MCP URL published at [deepledger.ai](https://deepledger.ai) is `https://mcp.deepledger.ai/mcp`, registered as `ai.deepledger/mcp` in the official MCP Registry.

## Features

- Full bookkeeping through chat, voice, or file uploads.
- Bill, expense, invoice, receipt, payment, and journal entry workflows.
- Month-end close and QBO cleanup assistance.
- Audit preparation and command-center style financial operations.
- QuickBooks Online OAuth connector setup without local plugins.

## Use Cases

- Record a stack of uploaded receipts as categorized expenses for review.
- Reconcile last month's bank feed exceptions before close.
- Draft month-end adjusting entries with supporting explanations.
- Clean up stale accounts and misclassified transactions in QBO.
- Prepare an audit request packet from current books.

## Installation

### Claude (Connectors)

1. Open **Settings → Connectors**.
2. Add `https://mcp.deepledger.ai/mcp`.
3. Complete QuickBooks Online authorization when prompted.

### ChatGPT Apps

Paste the DeepLedger MCP URL into ChatGPT Apps configuration per DeepLedger's setup guide.

### Claude Code

```bash
claude mcp add --transport http deepledger https://mcp.deepledger.ai/mcp
```

Follow the step-by-step setup guide linked from [deepledger.ai](https://deepledger.ai).

## Configuration

```json
{
  "mcpServers": {
    "deepledger": {
      "url": "https://mcp.deepledger.ai/mcp",
      "type": "http"
    }
  }
}
```

Authentication is handled through DeepLedger and QuickBooks OAuth, not static API keys in the JSON snippet.

## Security

- Require human review before posting material journal entries or tax-sensitive changes.
- Connect only the QBO companies and roles necessary for the assistant's scope.
- Revoke OAuth access if a shared machine or contractor offboarding occurs.

## Troubleshooting

### Connector auth failures

Re-run QuickBooks authorization from DeepLedger and confirm the QBO user still has API access.

### Transactions not appearing

Check whether entries were saved as drafts awaiting human approval rather than posted.

### Permission denied on specific accounts

The connected QBO role may lack access to banking, payroll, or restricted classes.

### Wrong company connected

Switch the authorized QuickBooks company in DeepLedger before running bookkeeping tools.
