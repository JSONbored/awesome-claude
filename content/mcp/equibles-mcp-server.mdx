## Content

Equibles MCP Server is a hosted remote MCP server at
`https://mcp.equibles.com/mcp` (Streamable HTTP). It connects Claude and other
MCP clients to US company research data with links back to the source
documents: SEC filing search and filing text, fundamentals as reported in
10-K and 10-Q filings, earnings-call transcripts, 13F institutional holdings,
insider and congressional trades, and FRED macro series.

Clients sign in with OAuth, or send an Equibles API key as a Bearer token. The
open-source core of the service lives at `daniel3303/Equibles` and can be
self-hosted; the hosted server adds further datasets on top.

## Features

- Search SEC filings (10-K, 10-Q, 8-K, 20-F, 6-K) and read filing text.
- Retrieve income statement, balance sheet, and cash flow figures as reported in filings.
- Read earnings-call transcripts.
- Query 13F institutional holdings and quarter-over-quarter changes.
- Look up insider and congressional trades.
- Retrieve FRED economic indicators.
- Connect over Streamable HTTP with OAuth or an API key.

## Installation

For Claude Code:

```bash
claude mcp add --transport http equibles https://mcp.equibles.com/mcp
```

For clients configured with JSON:

```json
{
  "mcpServers": {
    "equibles": {
      "type": "http",
      "url": "https://mcp.equibles.com/mcp"
    }
  }
}
```

Sign in with Equibles when the client opens the OAuth flow, or send
`Authorization: Bearer <API key>` from clients that use keys.

## Use Cases

- Pull a company's last four quarters of revenue as reported in its 10-Q filings, with links to each filing.
- Find which institutions added to a position in the latest 13F quarter.
- Summarize what management said about guidance on the most recent earnings call.
- Check recent insider purchases before reading a 10-K section.

## Safety and Privacy

Equibles is a research data source. Treat model-generated conclusions as draft
research and verify figures against the linked filings before using them in
investment, reporting, or compliance work. Tool calls send tickers, filters,
and search text to Equibles, and portfolio tools store the positions you add in
your Equibles account, so keep client details out of prompts, and keep API keys
out of shared configuration.
