## Content

anymd, formerly PDF Reader MCP, is a local Model Context Protocol server and
CLI that turns files into clean Markdown for agents. It reads PDF, Word
(`.docx`), PowerPoint (`.pptx`), Excel/ODS/CSV/TSV, EPUB, HTML and web URLs,
Markdown/text/JSON, images (dimensions, EXIF, optional OCR), and audio/video
metadata and subtitles. The engine is native Rust, and it needs no API key or
cloud service.

For PDFs, anymd rebuilds words from glyph positions, keeps two-column papers in
reading order, and recovers tables, including borderless ones. Every page carries a
`<!-- page N -->` anchor that Claude can cite.

(`read_pdf`, `search_pdf`) still work for the current major version.

## Features

- npm package `@sylphx/anymd`. It runs as a stdio MCP server with `npx -y @sylphx/anymd`.
- `read` turns a file, URL, or folder into Markdown, with page ranges, a token budget, and a cursor for large documents.
- `search` finds text across files, folders, and URLs, and falls back to BM25-ranked passages.
- `inspect` renders PDF pages, extracts regions, runs OCR on pages, returns structure with geometry, and compares documents.
- The same binary works as a CLI: `anymd report.pdf > report.md`.
- `--allow-dir` directory confinement, and SSRF-safe URL fetching.
- Binaries for macOS, Linux, and Windows.
- MIT license.

## Installation

```json
{
  "mcpServers": {
    "anymd": {
      "command": "npx",
      "args": ["-y", "@sylphx/anymd"]
    }
  }
}
```

With Claude Code: `claude mcp add anymd -- npx -y @sylphx/anymd`. Add
`--allow-dir=/path/to/docs` to keep the server inside one folder.

## Use Cases

- Convert a PDF, deck, or spreadsheet to Markdown before summarizing it.
- Search a folder of contracts or papers for a phrase and cite the pages.
- Read a web article without navigation, banners, or sidebars.
- Extract tables from reports and invoices as Markdown tables.
- Read image EXIF data or video chapters and subtitles.

## Safety and Privacy

anymd can expose everything a document contains, including hidden metadata,
comments, and image GPS data. Use `--allow-dir` for private workflows, and
verify extraction quality before relying on important tables or scanned-document
text.
