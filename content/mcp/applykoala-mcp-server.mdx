## Overview

ApplyKoala is a job search tracker with a hosted Model Context Protocol server. Connected to Claude, your AI keeps the whole search in one place between conversations: the jobs you want, the companies, your resumes, the people you talk to and every application. You can see and change all of it on your own board at [applykoala.com](https://applykoala.com).

Setup guides are at [applykoala.com/mcp](https://applykoala.com/mcp); the server is at `https://applykoala.com/mcp` (streamable HTTP, OAuth sign-in).

## Features

- Save job postings word for word, with how you fit, quoting your own resume.
- Research companies: what they do, size, funding, ratings, visa sponsorship and news, each with a source and the date it was checked.
- Record applications and their status, including updates read from your job emails.
- Keep recruiters and other contacts, with the main points of each conversation.
- Build a bank of interview stories, run mock interviews and debrief real ones.
- Job alerts for new postings on companies' own careers pages.

## Use Cases

- "Find backend jobs in Singapore that fit my resume and save the good ones."
- "Look into these three companies. Do they sponsor work visas?"
- "Save the recruiter in this screenshot and what we talked about."
- "Which applications have had no answer for two weeks?"
- "Give me a mock interview for that job, with the salary round."

## Installation

### Claude (Connectors)

1. Open **Settings → Connectors → Add custom connector**.
2. Paste `https://applykoala.com/mcp`.
3. Sign in to ApplyKoala and press **Allow**.

### Claude Code

```bash
claude mcp add --scope user --transport http applykoala https://applykoala.com/mcp
```

Then type `/mcp`, choose applykoala and sign in.

### Other MCP clients

Codex: `codex mcp add applykoala --url https://applykoala.com/mcp`, then `codex mcp login applykoala`. Cursor and other clients: use the JSON configuration below.

## Configuration

```json
{
  "mcpServers": {
    "applykoala": {
      "url": "https://applykoala.com/mcp",
      "type": "http"
    }
  }
}
```
