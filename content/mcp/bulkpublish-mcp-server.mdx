## Overview

BulkPublish exposes a **hosted MCP endpoint** at `https://mcp.bulkpublish.com` for social media
publishing. The official docs list 20 operations, including **list_channels**, **create_post**,
**update_post**, **publish_post**, **list_posts**, **get_post_metrics**, **get_queue_slot**,
**upload_media**, **list_media**, and **get_analytics**. Posts can target Facebook, Instagram,
X, TikTok, YouTube, Threads, Bluesky, Pinterest, Google Business, LinkedIn, Mastodon, Discord,
Telegram, Tumblr, and Snapchat.

## Installation

```bash
claude mcp add --transport http bulkpublish https://mcp.bulkpublish.com
```

Complete the OAuth sign-in when prompted. An npm package (`@bulkpublish/mcp-server`) is also documented.
