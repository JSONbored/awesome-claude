## Content

AffixIO MCP is a local stdio Model Context Protocol server that wraps the
`affixio` SDK. It gives Claude three tools for host-side ACTION attestation:

- `attest_action` — create a signed yes/no record that an action happened on the host
- `verify_action` — verify an attestation or receipt
- `gate_tool_call` — allow or deny a privileged tool call with a signed decision

Install with `npx -y @affixio/mcp@0.1.0` (pinned). No remote MCP endpoint is required. PII is
intended to stay on the host; this is not a KYC flow.

## Verification

1. Run `npx -y @affixio/mcp@0.1.0 probe` and confirm the process starts.
2. Add the `copySnippet` config to Claude Desktop or Claude Code.
3. Ask Claude to call `attest_action` with a sample action string, then
   `verify_action` on the returned attestation.
