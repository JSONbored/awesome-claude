## Content

Keenable MCP Server connects MCP clients to Keenable's web search, which runs on
Keenable's own crawler, index, and ranking, and to a page fetcher that returns
clean Markdown. It is a hosted Streamable HTTP server, with an npm stdio bridge
for clients that only speak stdio.

The hosted endpoint answers without an API key on a shared public tier that is
rate-limited per IP (1,000 requests per hour, up to 10 per second). Passing an
`X-API-Key` header removes the hourly cap. Claude users can also add it from
Claude's Connectors Directory as **Keenable Web Search**.

## Features

- Hosted remote MCP endpoint (Streamable HTTP) at `https://api.keenable.ai/mcp`.
- `search_web_pages` for web search with titles, URLs, and snippets.
- `fetch_page_content` for fetching a known URL as clean Markdown.
- Keyless public tier; optional `X-API-Key` header for higher limits.
- Stdio bridge through `npx -y @keenable/mcp` (`KEENABLE_API_KEY` optional).
- Listed in the Official MCP Registry as `ai.keenable/web-search`.

## Installation

For Claude Code, add the hosted server for all projects:

```bash
claude mcp add --transport http --scope user keenable https://api.keenable.ai/mcp
```

To use your own key, append `--header "X-API-Key: keen_<your_key>"`.

For clients that support remote MCP servers:

```json
{
  "mcpServers": {
    "keenable": {
      "type": "http",
      "url": "https://api.keenable.ai/mcp"
    }
  }
}
```

For clients that need stdio:

```json
{
  "mcpServers": {
    "keenable": {
      "command": "npx",
      "args": ["-y", "@keenable/mcp"]
    }
  }
}
```

On claude.ai, Claude Desktop, and mobile, open **Customize → Connectors**, search
for **Keenable Web Search**, and click **Connect**.

## Use Cases

- Look up current documentation, release notes, or changelogs while coding.
- Fetch a known page as Markdown and summarize or quote it.
- Ground research answers in fresh web sources with citations.
- Give agents web search without managing an API key during evaluation.

## Safety and Privacy

Web content can contain prompt injection, incorrect claims, or malicious
instructions. Keep model instructions separate from fetched content and verify
important answers against primary sources.

Search queries and fetched URLs can reveal sensitive research topics. Protect API
keys and review Keenable's current privacy posture before using this server with
proprietary, regulated, or customer-specific work.
