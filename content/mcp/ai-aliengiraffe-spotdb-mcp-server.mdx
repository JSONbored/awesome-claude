## Overview

SpotDB provides a lightweight ephemeral data sandbox for LLM and agentic workflows. Upload CSV files, snapshot states, and query through MCP or REST APIs with guardrails that keep exploration away from production databases.

Full documentation is in [aliengiraffe/spotdb DOCS.md](https://github.com/aliengiraffe/spotdb/blob/main/DOCS.md). Claude Code connects via `mcp-remote` to `http://localhost:8081/stream`.

## Features

- Ephemeral SQL sandbox for uploaded CSV and tabular data.
- Snapshot and restore point-in-time dataset states.
- MCP stream API on localhost:8081 plus REST on 8080.
- Explorer UI for manual upload and query.
- Guardrails and optional API key authentication.

## Use Cases

- Upload a sales CSV and ask Claude to summarise top regions.
- Compare two snapshots of a dataset after ETL changes.
- Let an agent explore a sanitized customer extract without prod access.
- Prototype SQL questions before moving logic to a warehouse.
- Share exploratory results from the local Explorer UI.

## Installation

### Claude (Connectors)

1. Install and start SpotDB (`spotdb` or Docker).
2. Upload CSV data via curl or the Explorer at http://localhost:8080/explorer.
3. Add the MCP config using `mcp-remote http://localhost:8081/stream`.
4. Run exploratory queries through Claude Code or another MCP client.

### Claude Code

```bash
claude mcp add spotdb -- npx -y mcp-remote http://localhost:8081/stream
claude mcp list
```

### Other MCP clients

Add the connector using the JSON configuration below in your MCP client settings.

## Configuration

```json
{
  "mcpServers": {
    "spotdb": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://localhost:8081/stream"]
    }
  }
}
```

For authenticated setups:

```json
{
  "mcpServers": {
    "spotdb": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://localhost:8081/stream"],
      "env": {
        "X-API-Key": "YOUR_OPTIONAL_SPOTDB_KEY"
      }
    }
  }
}
```

Set optional `X-API-Key` when running SpotDB with authentication enabled.

## Security

- Never upload unredacted production PII without approval.
- Run SpotDB on localhost or trusted networks; protect port 8081 on shared machines.
- Treat query output as sensitive if source CSVs contained regulated data.

## Troubleshooting

### Connection refused

Ensure SpotDB is running and listening on port 8081.

### Table not found

Upload CSV with a table_name via POST /api/v1/upload first.

### Guardrail violation

Rewrite the query to stay within allowed operations per DOCS.md.

### mcp-remote errors

Update Node.js and retry `npx -y mcp-remote http://localhost:8081/stream`.
