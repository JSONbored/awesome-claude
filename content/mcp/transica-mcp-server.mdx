## Overview

Transica MCP (`dev.transica/transica`) is a public remote Model Context Protocol server from [Transica](https://transica.dev), which builds, hosts and lists MCP apps for ChatGPT and Claude. The server exposes Transica's two free tools so an assistant can run them in a chat.

Repository and setup notes: [TransicaDev/transica-mcp](https://github.com/TransicaDev/transica-mcp). Full reference: [transica.dev/docs/mcp](https://transica.dev/docs/mcp).

## Features

- `scan_webpage_ai_readiness`: scores one public web page out of 100 for AI agent readiness, with passed and failed checks, top fixes and a report link.
- `check_mcp_server_directory_rules`: connects to a public remote MCP server, reads its tool list and checks connection, sign-in, domain and tool rules against the ChatGPT and Claude directory requirements.

## Use Cases

- Check whether a site's pages are readable and usable by AI agents before launch.
- Pre-check an MCP server before submitting it to the ChatGPT or Claude directory.
- Compare a competitor's page or server against the same checks.

## Installation

### Claude (Connectors)

1. Go to **Customize → Connectors**, select **+ Add**, then **Add custom connector**.
2. Enter the name `Transica` and the URL `https://transica-mcp.transica.dev/mcp`.
3. Under **Authentication**, choose **No sign in**, then **Add**.

### Claude Code

```bash
claude mcp add --transport http transica https://transica-mcp.transica.dev/mcp
```

## Configuration

```json
{
  "mcpServers": {
    "transica": {
      "url": "https://transica-mcp.transica.dev/mcp",
      "type": "http"
    }
  }
}
```

No authentication headers are needed.

## Security

- Read-only tools; nothing is changed on the scanned page or checked server.
- Only public addresses are accepted.

## Troubleshooting

### Scan returns `running`

Scans longer than about 12 seconds return `running` with a report link; open it after a minute.

### Daily limit reached

The connector allows 5,000 scans and 5,000 checks a day across all users; the count resets at midnight UTC.
