# Court Rules

Court Rules is a remote MCP server for U.S. court filing rules. It answers what page limits, formatting rules, standing orders, and deadlines apply in front of a named judge, and when a court is closed, from the court's own published documents.

Every rule carries a citation back to the page and section of the order it came from. Coverage includes 1,000+ federal judges with extracted filing rules, 692 state and local courts with resources, holiday calendars through 2027, and 1,504 privacy enforcement actions across 16 jurisdictions.

## Tools

All nine tools are read-only:

- `list_courts` and `search_judges` find the court and judge.
- Rule tools return local rules, standing orders, page limits, and formatting requirements with citations.
- Holiday and deadline tools return court closure calendars and computed filing deadlines.

## Setup

Add the hosted server:

```bash
claude mcp add --transport http court-rules https://mcp.courtrules.app/mcp
```

Run `/mcp` in Claude Code, select `court-rules`, and choose Authenticate. Scripts and backends can skip sign-in by sending an API key from https://console.courtrules.app as an `Authorization: Bearer` header.
