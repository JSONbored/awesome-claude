## Content

This is a duplicate-test entry that intentionally points at the same source
(`https://github.com/JSONbored/gittensory` and the `@jsonbored/gittensory-mcp`
npm package) as the existing Gittensory MCP listing. It exists only to verify
that the maintainer review agent detects and acts on a strict duplicate. It
should be closed automatically.

## Features

- Local stdio MCP server for Claude, Codex, Cursor, and other MCP clients.
- Metadata-only branch analysis and preflight blockers.
- Public-safe PR packet drafting.

```bash
claude mcp add gittensory -- npx -y @jsonbored/gittensory-mcp@latest --stdio
```
