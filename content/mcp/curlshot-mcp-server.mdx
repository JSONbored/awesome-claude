## Overview

CurlShot is a website screenshot API. Its hosted MCP endpoint at
`https://curlshot.com/api/mcp` (streamable HTTP) exposes two tools:

- **take_screenshot**: render a public web page and return it as an image (JPEG, PNG,
  WebP), a PDF, or a video of the page scrolling from top to bottom (MP4, WebM, GIF).
  Options include `full_page`, `viewport_device`, `viewport_width`/`viewport_height`,
  `dark_mode`, `selector` (one element), `block_ads`, `block_cookie_banners`,
  `wait_until`, `delay` and `cache`. Results over 6 MB come back as a download link.
- **list_devices**: list the phone, tablet and desktop presets accepted by
  `viewport_device`. Needs no access key.

## Installation

```bash
claude mcp add --transport http curlshot https://curlshot.com/api/mcp \
  --header "Authorization: Bearer YOUR_ACCESS_KEY"
```

Get an access key from a free CurlShot account at https://curlshot.com/register
(100 screenshots a month, no card).
