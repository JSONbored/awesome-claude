## Content

Atlassian Rovo MCP Server is Atlassian's official remote MCP surface for Jira,
Confluence, Compass, and related Atlassian Cloud workflows. Atlassian documents a
new `/mcp` endpoint and OAuth-backed setup for clients and local MCP-compatible
IDEs through `mcp-remote`.

## Use Cases

- Search Jira and Confluence without leaving an AI client.
- Summarize project context before drafting specs or tickets.
- Create or update issues and pages when permissions and approval flow allow it.
- Bring Atlassian Cloud knowledge into an IDE or local assistant workflow.

## Safety and Privacy

Atlassian content often contains customer names, incident details, roadmap notes,
security work, and internal planning. Keep OAuth scopes narrow, use test spaces
for early trials, and require human approval for write operations.
