## Overview

Floot is an app platform exposed through the Model Context Protocol. Claude writes the code into a Floot project; Floot runs it and supplies the backend pieces: a managed Postgres database, user sign-in (email and password, Google, Microsoft), file storage, sending and receiving email, push notifications, scheduled and background jobs, Stripe payments, and hosting. A live preview updates as Claude edits, and a project can be published to a floot.app address or a custom domain. Projects can also be built into iOS and Android apps.

Documentation: [floot.com/docs/integrations/other-mcp-clients](https://floot.com/docs/integrations/other-mcp-clients). Endpoint: `https://mcp.floot.com/mcp` (Streamable HTTP, OAuth).

## Features

- create_project, read_file, write_file, edit_file and apply_patch for building the app.
- provision_resource to add a database, sign-in, storage, email and other services without separate accounts or API keys.
- query_database and execute_sql against the project's own Postgres database.
- typecheck, run_tests, get_logs and screenshot_preview for checking the app while it is built.
- publish_app and get_publish_status to put the app live, and create_checkpoint for restore points.

## Use Cases

- Build a client portal where customers sign in and see their own records.
- Add a database, login and hosting to an app Claude has already written.
- Build an internal tool for a team, published so only invited people can open it.
- Add scheduled reminders or email notifications to an existing Floot app.
- Fix a bug in a published app by reading its logs and republishing.

## Installation

### Claude (Connectors)

1. Add Floot from Claude's connector directory, or open **Settings → Connectors → Add custom connector**.
2. For a custom connector, name it Floot and set the URL to `https://mcp.floot.com/mcp`.
3. Complete the Floot sign-in in the browser window that opens.
4. Mention Floot in your first message so Claude uses its tools.

### Claude Code

```bash
claude mcp add --transport http floot https://mcp.floot.com/mcp
claude mcp list
```

### Other MCP clients

Add a remote server with the configuration below. Choose Streamable HTTP if the client asks for a transport, and leave any bearer-token, API-key or header fields empty.

## Configuration

```json
{
  "mcpServers": {
    "floot": {
      "url": "https://mcp.floot.com/mcp",
      "type": "http"
    }
  }
}
```

OAuth handles authentication; no API key is used.

## Security

- Review database changes and publishing before approving them.
- Apps that store personal data should use sign-in and keep each user's records private; ask Claude to check this before publishing.
- Use internal publishing for tools that only your team should open.

## Troubleshooting

### Nothing loads at the server URL in a browser

That is expected: `https://mcp.floot.com/mcp` answers MCP requests, not web pages. Add it in your client's MCP settings.

### Client asks for a token or API key

Leave it empty. Floot signs you in with OAuth in the browser.

### Connection fails during sign-in

Floot accepts only PKCE with `S256`; a client that offers only `plain`, or no PKCE, cannot connect.

### Tools don't appear in the chat

Some clients need the server's tools enabled per chat. Enable Floot and mention it in your message.
