## Content
Mach GTM MCP is a small, open-source Model Context Protocol server that brings
five outbound sales helpers into Claude and other MCP clients. The tools shape
what you give them into an ideal customer profile, a drafted message, a
research checklist, a lead score or a multi-touch sequence. They do not search
the web or look anything up, so every fact in the output is one you supplied.

## Features
- **`build_icp`** — Turn a company description and best customers into a
  structured ideal customer profile.
- **`research_prospect`** — Get a research checklist and the questions to answer
  before you reach out.
- **`score_lead`** — Score a lead 0-100 against your ICP with a simple, readable
  formula and reasons for and against.
- **`draft_outreach`** — Draft a cold email or LinkedIn message from a buying
  signal and a proof point you provide.
- **`build_sequence`** — Lay out a multi-touch cadence with timing for each step.
- MIT-licensed; runs from GitHub with a single `npx` command.
## Installation
Add the server to your Claude Code MCP configuration:
```json
{
  "mcpServers": {
    "mach-gtm": {
      "command": "npx",
      "args": ["-y", "github:verma6uc/mach-gtm-mcp"]
    }
  }
}
```
Or start it directly:
```bash
npx -y github:verma6uc/mach-gtm-mcp
```
## Configuration
No environment variables or accounts are required.
## Use Cases
- Turn a company description and best customers into an ICP draft.
- Draft a first message from a buying signal you have already found.
- Score a handful of leads against your ICP before a sales call.
- Lay out a five-touch outbound sequence for a product launch.
## Safety and Privacy
The server runs locally and does not send messages or make network requests.
Read every draft and check each fact in it before you use it.
