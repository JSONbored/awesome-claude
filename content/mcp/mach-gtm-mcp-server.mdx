## Content

Mach GTM MCP is an open-source Model Context Protocol server that brings
B2B outbound sales workflows into Claude and other MCP clients. It exposes
five tools covering the full top-of-funnel cycle: defining an ideal customer
profile, researching prospects with verified buying signals, scoring lead fit,
drafting personalised outreach, and building multi-touch sequences.

The server is built with a human-in-the-loop design — every outreach draft
requires explicit approval before any message leaves the system.

## Features

- **`build_icp`** — Define your ideal customer profile with firmographic and
  technographic criteria.
- **`research_prospect`** — Gather verified buying signals for a target company
  or contact, grounded in real data rather than scraped lists.
- **`score_lead`** — Score prospect fit on a 0-100 scale against your ICP.
- **`draft_outreach`** — Write personalised cold emails and LinkedIn messages
  using the 1-3-1 framework (one hook, three value points, one call to action).
- **`build_sequence`** — Generate multi-touch cadences combining email,
  LinkedIn, and other touchpoints.
- Human-approval gate: no message is transmitted without explicit user sign-off.
- MIT-licensed; install with a single `npx` command, no global install needed.

## Installation

Add the server to your Claude Code MCP configuration:

```json
{
  "mcpServers": {
    "mach-gtm": {
      "command": "npx",
      "args": ["mach-gtm-mcp"]
    }
  }
}
```

Or start it directly:

```bash
npx mach-gtm-mcp
```

## Configuration

No environment variables are required for basic use. Connect your Mach GTM
account at machgtm.com to unlock prospect research and verified signal data.

## Use Cases

- Research a list of target accounts and score each against your ICP before
  a sales call.
- Draft personalised cold emails for a batch of prospects without leaving
  Claude Code.
- Build a five-touch outbound sequence for a new product launch in minutes.
- Score inbound leads automatically as they arrive and route high-fit contacts
  to your sales team.

## Safety and Privacy

The Mach GTM MCP server is designed around a human-in-the-loop principle.
Drafting tools produce copy for review; no message is sent without your
explicit approval. Prospect research uses verified, signal-grounded data.
Review machgtm.com's privacy policy for details on how prospect and contact
data is handled by the platform.
