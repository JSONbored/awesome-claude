This Stop hook runs automatically when your Claude Code session ends, detects which package manager your project uses by checking for lockfiles, and invokes the appropriate audit tool — no configuration per project required.

**Package manager detection order:**
- `package-lock.json` → `npm audit --audit-level=moderate` + `npm outdated`
- `yarn.lock` → `yarn audit --level moderate`
- `requirements.txt` / `Pipfile` / `pyproject.toml` → `safety check`
- `Gemfile.lock` → `bundle exec bundler-audit check`

Each run writes a timestamped `security-audit-YYYYMMDD_HHMMSS.log` in the project root with full output. Add `security-audit-*.log` to `.gitignore` to keep reports local.

## Installation

1. Save the hook script to `.claude/hooks/dependency-security-audit-on-stop.sh`
2. Make it executable: `chmod +x .claude/hooks/dependency-security-audit-on-stop.sh`
3. Add the hook configuration below to your settings file

**Settings file locations:**
- Project-wide (committed): `.claude/settings.json`
- Local only (not committed): `.claude/settings.local.json`
- Global: `~/.claude/settings.json`

## Requirements

- Claude Code CLI
- Bash shell
- At least one supported audit tool for your stack:
  - **Node.js**: `npm` (built in to npm 6+) or `yarn` (any version supporting `yarn audit`)
  - **Python**: `safety` (`pip install safety`) — falls back to `pip list --outdated` if unavailable
  - **Ruby**: `bundler-audit` (`gem install bundler-audit`) — must be available in the bundle
- Network access to the relevant advisory database (npm registry, PyPI Advisory Database, or Ruby Advisory Database)

## Troubleshooting

### Audit log files accumulate in the project root

Set `REPORT_FILE` to a dedicated path, e.g. `.claude/logs/security-audit-$TIMESTAMP.log`. Add `security-audit-*.log` to `.gitignore` so reports stay out of version control.

### npm audit hangs on network issues

Wrap the call with a timeout: `timeout 60 npm audit`. Use `npm audit --offline` to fall back to locally cached advisory data. Set a registry timeout with `npm config set timeout 30000`.

### Safety scanner fails with "database not found"

Run `safety check --update-db` to refresh the local database, or upgrade: `pip install --upgrade safety`. As an alternative, install `pip-audit` (`pip install pip-audit`) and adapt the Python branch of the script to call `pip-audit` instead.

### Audit severity flags not recognised by older npm

The `--audit-level` flag requires npm 6+. For older versions, remove the flag and filter severity from the full output with `grep`. Check your version with `npm --version`.

### bundler-audit requires bundle install first

Run `bundle install` before the audit: `bundle install && bundle exec bundler-audit check`. Ensure `Gemfile.lock` is present and `bundler-audit` is installed globally or in the bundle.
