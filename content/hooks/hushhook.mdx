## Features

- Masks secrets in tool output before they enter the conversation, with rules for 42 token and key formats.
- Blocks reads of sensitive files such as `.env`, private keys, cloud credentials and `terraform.tfstate`.
- Stops big dumps, such as a whole log file, and points the agent at a smaller view instead.
- Catches risky commands, such as piping a download straight into a shell.
- `hushhook map` and `hushhook peek` give the agent a file outline or a single function instead of the whole file.

## How it works

`PreToolUse` checks `Read` and `Bash` calls against plain-text rule files and returns a clear reason when it blocks one, so the agent can adjust and carry on by itself. `PostToolUse` scans tool output for known secret formats and replaces them with a tag such as `[hushhook:github-classic-token]`.

## Use cases

- Working in a repository with real `.env` files and credentials nearby.
- Letting an agent read logs without filling the conversation.
- Adding a rule for an internal token format your team uses.

## Installation

As a Claude Code plugin:

```text
/plugin marketplace add monarchsofchaos004-gif/hushhook
/plugin install hushhook@hushhook
```

As a command line tool:

```bash
pipx install git+https://github.com/monarchsofchaos004-gif/hushhook
hushhook install
```

`hushhook install` backs up `settings.json` first, and `hushhook uninstall` removes only what it added.

## Requirements

- Python 3.9 or newer, with no other dependencies.
- Tested on Linux and macOS in CI.

## Hook configuration

Settings live in `~/.config/hushhook/config.json`. Use `disabled` to turn off a rule by id, `extra_rule_dirs` to load your own rule files, and `max_read_lines` to change the size limit.

## Limitations

- Only known formats are masked. A secret with no matching rule gets through.
- A script that reads a file itself and prints it in a new shape is not caught by the file rules.
- Command rules also match text inside quotes, so a commit message that mentions a blocked command can be stopped.
