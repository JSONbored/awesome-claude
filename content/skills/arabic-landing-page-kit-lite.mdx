## Overview

Arabic Landing Page Kit Lite is a free MIT-licensed starter for service
businesses. It ships one Arabic RTL design, a JSON brief contract, a Python
standard-library generator, a fictional example and editable static files.
The documentation is primarily English with Arabic, Spanish and Chinese
translations. Those guides do not turn the generated Arabic page into four
page languages.

## Install and Invoke

Clone the repository or download its source ZIP. Read SKILL.md, the brief
contract and the bundled Python script before execution. For assistant use,
copy the entire `skills/arabic-landing-page-kit-lite/` folder to your project's
`.claude/skills/arabic-landing-page-kit-lite/` directory and invoke
`/arabic-landing-page-kit-lite`. The documented Codex destination is
`.agents/skills/arabic-landing-page-kit-lite/`, invoked with
`$arabic-landing-page-kit-lite`.

These are documented paths, not verified automatic-discovery claims. You can
also use the local generator without an AI assistant. From the repository root:

```sh
python3 skills/arabic-landing-page-kit-lite/scripts/build_page.py --brief skills/arabic-landing-page-kit-lite/examples/brief.json --output work/my-page
```

The output path must not exist. Open `work/my-page/index.html` locally, keeping
the generated HTML, CSS and JavaScript together. For another page, edit a copy
of the example brief and choose a different new output directory.

## Core Workflow

1. Read the brief contract and use supplied business identity, services,
   audience and offer facts. Keep `demo: true` for fictional content.
2. Run the generator with skill-relative script paths and project-relative
   brief/output paths. The result contains a hero, one to six services, one to
   four process steps and a contact-preview form.
3. Keep Arabic `lang` and RTL direction, logical spacing and isolated Latin
   text. Review line breaks and narrow screens. The CSS illustration is
   decorative, not a photograph of completed client work.
4. Inspect the generated files and test navigation, required fields, summary
   dialog, copy and local text download where browser tools are available.
5. Return the complete editable directory. Explain that the contact flow is a
   local preview and report untested behavior. The kit supplies no hosting,
   live lead collection or guaranteed business result.

## Verification and Limits

The source's
[validation record](https://github.com/medenh/arabic-landing-page-kit-lite/blob/e56e5837eba3359561b42dbcac926c1adeb5b91e/VALIDATION.json)
reports thirteen generator regressions, frontmatter and JavaScript syntax
checks, 1280px/390px browser layout checks, invalid-input handling, local
summary/copy and downloaded-text checks. Those checks establish specific
script/browser behavior.

In a separate exercise on 2026-11-28, an actual Codex agent manually read
SKILL.md and the complete brief contract, authored a fresh fictional home-office
service brief, and invoked the real generator through its tools. Generation
exited successfully. Narrow static checks covered supplied-field rendering,
Arabic/RTL markup, escaping, demo/local-contact labels and refusal to overwrite
an existing output directory. `testedPlatforms: Codex` refers only to that
explicitly loaded agent execution, not installed-skill discovery or a standalone
Codex CLI test. The fresh exercise did not repeat browser interaction checks.

`verificationStatus: draft` reflects this limited scope. No Claude Code,
