  # Lava - News Heat Monitor (熔岩 · 消息面热度监测)

  Data source: Lava remote MCP https://lava.ai-dolphin.com/subscribe/v1/mcp (Streamable HTTP, header Authorization: Bearer <API Key>). All tools are read-only. Each tool call counts as 1 request (get_account does not).

  ## Setup
  1. Get an API Key (lvk_...) at https://lava.ai-dolphin.com/lava#/ai-data-service
  2. Add a custom MCP connector (Streamable HTTP) with URL https://lava.ai-dolphin.com/subscribe/v1/mcp and header Authorization = Bearer lvk_YOUR_KEY
  3. Ask e.g. "Is CATL hot in news flow this week?"

  ## Workflow
  1. Stock heat: get_stock_news_heat(stock_name or ts_code, days=7) - read data.heat.mentions, data.heat.agencies, summarize list[].summary.
  2. Related concepts: get_stock_concept_heat(stock_name, days=30) - top 5 concepts with mentions.
  3. Concept ranking: get_concept_stock_heat(concept, days=7).
  4. Tracking: search_news_flow(keyword, since); get_market_hot_stocks / get_market_hot_concepts(window=24h); get_weighted_hot_stocks(days=3); get_first_mention_stocks(hours=24); get_news_stock_hits; get_stock_heat_windows; get_accelerating_hot_stocks; get_stock_heat_panel; get_agency_coverage.
  5. Optional credibility: get_agency_pit / get_agency_history on agency_id.
  6. On 402 / INSUFFICIENT_BALANCE tell the user to top up; report other errors as-is, do not retry repeatedly.

  ## Output
  Lead with conclusion: heat high/medium/low + mentions + agencies + time window; 3-5 concise bullets; plain language; cite agency_id; note data is from Lava.
