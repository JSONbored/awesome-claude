# Multi-LLM Plan and Code Review Skill

Multi-LLM is an MIT-licensed plugin and `SKILL.md` workflow maintained by
beastlabai. From Claude Code, it runs a plan or code review through multiple
configured coding CLIs and consolidates their findings. It also supports task
generation, implementation, and commit review. Native Codex and OpenCode
installation routes are documented upstream; this entry's invocation examples
use the Claude Code plugin.

## Installation

Install the marketplace and plugin using the commands above, reload plugins
and skills, then run `--init` once in the project. Review the generated
`.multi-llm/providers.yaml`: a default run invokes the configured model panel,
so select the providers and models you intend to use before starting a review.
The plugin does not install or authenticate the provider CLIs for you.

## Usage

For an existing Markdown implementation plan, invoke:

```text
/multi-llm:multi-llm --review-plan plans/my-feature.md
```

The inputs are a plan or commit range, a selected workflow mode, and provider
configuration. Outputs include structured review reports and workflow state.
Implementation and apply/fix modes additionally produce code or plan edits
through the host workflow. Inspect those diffs before committing.

## Safety and Privacy

Provider CLIs execute locally and use their configured permissions and
credentials. Review-only modes still invoke model providers; write-capable
modes can edit repository files. Source context and review artifacts can be
sensitive. Choose providers appropriate for that data, account for their
usage costs, and keep local credentials and private reports out of public
repositories.

## Troubleshooting

If invocation fails, confirm `uv`, Git, and the selected provider CLIs are
available and authenticated, then inspect the project provider configuration.
Use the upstream host-specific installation and troubleshooting documentation
for Codex and OpenCode rather than copying the Claude Code slash command.
