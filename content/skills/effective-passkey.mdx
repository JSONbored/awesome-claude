# EffectivePasskey

EffectivePasskey is a free, MIT-licensed skill and CLI for Microsoft Entra ID
admins rolling out passkeys. Entra passkey profiles combine as a union while
Conditional Access combines as an intersection, so the policy a user actually
gets is hard to see in the portal. EffectivePasskey computes it per user from
read-only exports and explains the result.

## What it checks

- Each user's effective passkey policy after overlapping profiles and
  Conditional Access authentication strengths.
- Admins whose passkey rules are weakened by a broader profile.
- Who will be blocked when SMS and voice sign-in are retired.
- Temporary Access Pass bootstrap paths, tamperable groups, and admin attack
  paths.
- A remediation simulator that previews the effect of a fix before you apply
  it in the tenant.
