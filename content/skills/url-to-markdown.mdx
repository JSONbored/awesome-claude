## Overview

ReplyNodes URL to Markdown returns a public webpage as clean Markdown for agent context.

## Usage

```bash
curl -sS https://md.replynodes.com/example.com
```

Replace `example.com` with the public webpage host and path you want to retrieve. Read the [Markdown API documentation](https://replynodes.com/markdown-api/) for the request format and see the [canonical skill source](https://github.com/replynodes/replynodes-agent-skills/tree/main/skills/url-to-markdown).
