## What it does

The skill gives an agent a set of small shell scripts that call the getyoutubetranscript.com REST API:

- Fetch the transcript of a video, in any caption language the video has, with optional timestamps.
- Search YouTube globally or within one channel, and resolve a channel handle to its ID.
- List the videos in a playlist, and a channel's videos, Shorts, live streams, playlists and community posts.
- Check the remaining credit balance.

## Cost

The API is metered: 1 credit per successful request, failed requests are not charged. New accounts get 100 free credits; after that, paid plans apply. The skill tells the user the cost before creating an account.
