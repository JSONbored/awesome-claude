# Ponder Deliberation Loop Skill

Ponder is an open source, zero-dependency deliberation loop and coverage gate CLI and skill for AI coding agents. It wraps automated code reviews in an append-only ledger (`.ponder/<slug>/ledger.jsonl`) and blocks early completion until 100% of enumerated units in scope are graded and two consecutive quiet passes produce zero ledger deltas.

Coding agents often suffer from "forced speech" and early abandonment: they grade 11 of 12 files, declare victory, or spiral into low-precision nitpicks on later passes. Ponder enforces strict epistemic stopping: it evaluates code across four distinct personas (skeptic, builder, dreamer, empath) and prevents the agent from claiming a task is done until all units are accounted for.

## Knowledge Freshness

Ponder is actively maintained on Node.js 18+ with zero runtime npm dependencies. Ledger files and session states are strictly local to the repository workspace under `.ponder/`. For multi-agent environments, verify that the local Node runtime is version 18 or higher and that git diffs are available.

## Core Workflow

Install Ponder CLI or skill into your coding agent workspace:

```bash

# Or install globally via npm
npm install -g @quinnod345/ponder

# Install into Claude Code
ponder install claude-code
```

Inside Claude Code or Codex, you can invoke the review command directly:

```text
/ponder review
Audit all staged changes across skeptic, builder, dreamer, and empath perspectives.
Block completion until all units are graded and consecutive passes converge.
```

## Capability Scope

Ponder provides five core capabilities:

1. **Unit Enumeration**: enumerates all modified or specified source files as discrete review units.
2. **Coverage Gate**: blocks early completion unless every unit has received an evaluation score.
3. **Four Perspectives**: evaluates code across skeptic, builder, dreamer, and empath personas.
4. **Append-Only Ledger**: records all review judgments into an immutable `.ponder/<slug>/ledger.jsonl` history.
5. **Pass Convergence**: detects pass-to-pass deltas and stops only when two consecutive passes reach consensus.

## Production Rules

- Never declare a code review complete without checking `ponder decide stop`.
- Grade 100% of units before attempting to finalize the review session.
- Run consecutive passes until ledger churn drops to zero.
- Re-run review passes if code changes are made in response to review findings.
- Keep review findings grounded in concrete source line references.

## Use Cases

- **Pre-PR Review**: catch edge cases and architecture defects before opening a pull request.
- **CI Quality Gate**: integrate `action.yml` into GitHub Actions to block merge on ungraded code.
- **Agent Self-Audit**: prevent coding agents like Claude Code or Codex from stopping before all files are reviewed.
- **Adversarial Analysis**: evaluate security, performance, user empathy, and maintainability in parallel.

## Troubleshooting

### Decision exit code 2 (Ungraded units remaining)

Run `npx @quinnod345/ponder status` to inspect which units lack evaluation scores. Grade all remaining units before running `decide stop`.

### Decision exit code 3 (Pass-to-pass churn detected)

Run `npx @quinnod345/ponder delta` to inspect recent deltas. Run an additional quiet pass until two consecutive passes produce zero churn.

### Target environment selection

Pass the target environment explicitly: `ponder install claude-code`, `ponder install codex`, or `ponder install openclaw`.
