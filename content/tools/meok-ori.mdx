## Editorial notes

meok-ori is a zero-dependency Python harness for running other agent CLIs. The
`meok harness claude|codex|hermes` command wraps a coding agent with the harness
environment, and `meok run` gives you one completion through a local-first
four-tier cascade (T1 Edge up to T4 Strategic, cheapest tier that qualifies
first) with an offline stub fallback so the whole thing works with no network
and no API key.

Every run is audited against a 22-article constitution and exits non-zero when
an article fails: unknown models are refused by default, a cost budget is
checked before the call, and the receipt chain is re-verified after the run. A
deterministic keyword screen (13 rules, plus a PII regex and a length check)
optionally reviews outputs before you see them. Receipts are an append-only
HMAC chain under a local key — integrity against edits, not third-party
signatures — and `meok receipts --verify` re-checks the chain.

Reach for it when you want a small, auditable wrapper around the agent CLIs you
already use. It is model-agnostic, stdlib-only, and deliberately not a
framework: no plugins, no daemon, no dependencies.
