## Overview

Dario Paint is a local editor for Claude Code skills. It opens a `SKILL.md`
as large handwriting in a composition notebook, and you edit it by painting
over whole paragraphs, list items and headings with rubber stamps modeled on
Mario Paint.

The idea behind it is that skills work better when they read like a brief
from someone who trusts the reader (the goal, the boundaries, what good looks
like and why) than like a checklist of CRITICAL and ALWAYS rules. The stamps
push a skill in that direction.

## Core Capabilities

- Human stamp: Claude rewrites the painted part the way a person would brief a colleague, plainer and shorter, without granular steps.
- Einstein stamp: Claude rewrites the painted part as the principle underneath it, with the reason.
- Eraser removes the painted part; More and Less promote or demote headings and move other items up or down within their section or list.
- Pencil for direct edits, and editable front matter (name and description) with a length counter.
- Undo and save; saving refuses a skill without a name or description.
- `bun test` round-trips every skill on the machine byte-for-byte through the editor.

## Install

```bash
git clone https://github.com/Claude-Mem/dario-paint
cd dario-paint
bun install
bun start
```

Then open http://127.0.0.1:4848 and pick a skill. Extra skill folders can be
added through `EXTRA_SKILL_FOLDERS` in a `.env` file.

## Safety and Privacy

Opening a skill copies it into `.scratch/notebooks/`; every edit and save
happens on that copy, so the original skill is untouched until you copy the
result back yourself. Only the Human and Einstein stamps leave the machine,
through the user's own `claude -p` session.
