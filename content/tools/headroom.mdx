## Editorial notes

Headroom is the zero-network Claude Code companion. Instead of polling the Anthropic API, it installs a tiny statusline hook that runs inside Claude Code and writes the official 5h/7d rate-limit numbers to a local JSON file. The menu bar app reads that file every minute. The result is the same data `/usage` shows — session utilization, weekly utilization, context window fill, active model, session cost — visible at a glance in the menu bar without opening a terminal.

The architecture differentiates it from API-polling tools: no credentials needed, no network traffic, no 429 risks. It reads exactly what Claude Code itself tracks and publishes no further.
