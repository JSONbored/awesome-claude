## Editorial notes

reinwatch is useful when Claude Code delegates work to subagents, teammates or workflow agents and you need to see what each agent is doing. For every agent it shows new-token counts (cache reads excluded) and active time, adds turn summaries, and keeps 30-day totals available through `/reinwatch:status`.

Its warning layer covers the common failure shapes of delegated runs: an agent running longer than 30 minutes, passing 1M new tokens, repeating the same tool call, failing repeatedly, or many agents spawning in a short burst. When a run does go wrong, a single agent can be stopped without ending the rest of the session, including an agent working inside a workflow.

The fit for HeyClaude is strongest for developers who run multi-agent Claude Code sessions and want local, per-agent cost and behavior visibility without sending session data to an external service.
